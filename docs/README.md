## 1. 阅读顺序

1. 新成员和新对话先完整阅读根目录的 `2026-07-23-GAIOP当前状态与新对话交接入口.md`，尤其是其中 2026-07-30 持续权限和当前状态。
2. 完整阅读当前任务涉及仓库的 `AGENTS.md`。
3. 开发具体功能前按需阅读对应模块、接口和最近一次237发布记录；不要求开始任务前顺序读完全部历史文档。
4. 涉及数据库、权限、敏感信息或运行时配置时，同时阅读 `04-公共设计`。
5. 联调和发布前执行 `05-部署运维` 与 `06-测试验收` 中的检查项。
