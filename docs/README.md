# 观枢 GAIOP 开发文档中心

> 文档基线：2026-07-15
> 适用代码：`GAIOP-Admin` 前端与管理服务、`GAIOP` 智能体与 NAPM Skills
> 权威性：本目录是当前开发、联调、验收和部署的唯一正式文档入口。

## 1. 阅读顺序

1. 新成员先阅读[项目总体架构](01-总体设计/2026-07-15-GAIOP项目总体架构.md)。
2. 判断当前进度和下一步时阅读[开发进度与路线图](01-总体设计/2026-07-15-GAIOP开发进度与路线图.md)。
3. 开发具体功能前阅读对应的模块设计和接口设计。
4. 涉及数据库、权限、敏感信息或运行时配置时，同时阅读 `04-公共设计`。
5. 联调和发布前执行 `05-部署运维` 与 `06-测试验收` 中的检查项。

## 2. 目录结构

```text
docs/
├─ README.md
├─ 00-文档规范/
├─ 01-总体设计/
├─ 02-模块设计/
├─ 03-接口设计/
├─ 04-公共设计/
├─ 05-部署运维/
├─ 06-测试验收/
├─ 07-历史决策/
│  └─ images-原项目界面/       # 仅用于改造前后对照，不代表当前产品页面
└─ README.md
```

| 目录 | 用途 | 更新时机 |
|---|---|---|
| `00-文档规范` | 命名、模板、状态和维护规则 | 文档体系变化时 |
| `01-总体设计` | 产品边界、总体架构、进度与路线图 | 架构或优先级变化时 |
| `02-模块设计` | 单模块功能、页面、权限、流程和验收 | 模块开发前后 |
| `03-接口设计` | REST/RPC 契约、错误码和权限 | 接口同步变更时 |
| `04-公共设计` | 数据模型、权限安全、运行时边界 | 公共机制变化时 |
| `05-部署运维` | 本地开发、生产部署、环境变量和运维 | 部署方式变化时 |
| `06-测试验收` | 测试策略、回归范围和验收矩阵 | 功能交付时 |
| `07-历史决策` | 已被新基线替代但需追溯的决策 | 只归档，不作为实现依据 |

`07-历史决策/images-原项目界面` 保存原开源项目在 2026-07-11 进行功能盘点时的截图。正式模块是否存在、页面当前样式和功能状态，必须以模块设计和实际代码为准，不能以这些历史截图为依据。

## 3. 文档状态

| 状态 | 含义 |
|---|---|
| 已实现 | 页面、接口和主要流程已存在，并已完成基础验证 |
| 基础版本已实现 | 主流程可用，但仍有生产化、隔离或体验事项 |
| 保留原功能 | 原开源功能仍在使用，尚未完成 GAIOP 业务化收口 |
| 框架已建立 | 菜单、路由或占位页存在，业务接口未完成 |
| 待开发 | 尚未进入实现 |
| 已隐藏 | 正式菜单和路由不可达，源码暂时保留 |
