# 系统升级操作接口（第二阶段）

## 浏览器接口

仅管理员可访问，浏览器始终只连接 Admin BFF。

| 方法 | 路径 | 用途 |
|---|---|---|
| POST | /api/system-upgrade/validate | 上传 ZIP 并请求升级服务校验 |
| POST | /api/system-upgrade/tasks/:taskId/execute | 对已校验任务进行二次确认后执行 |

## 校验上传

请求为 multipart/form-data，字段 file 仅接受 ZIP，最大 500MB。Admin BFF 先写到受控临时目录，再以流式 multipart 请求转发给升级服务；请求结束后立即删除 BFF 暂存文件。

成功响应中的 validation 只含校验结果、组件、版本、影响和受限数量的错误信息，不返回服务地址、令牌、服务器路径或上传文件的真实存放位置。

## 执行确认

执行请求体必须包含 confirmation，值严格为 EXECUTE。BFF 不接受客户端指定的操作者、force 或任意服务端路径；操作者由当前已认证管理员派生，实际升级服务也会记录审计。

服务端接受后返回 202。任务异步执行，页面通过总览刷新查看最新状态。本阶段尚未提供回滚与备份删除入口。

## 错误码

- UPGRADE_PACKAGE_REQUIRED
- UPGRADE_PACKAGE_FORMAT_INVALID
- UPGRADE_PACKAGE_TOO_LARGE
- UPGRADE_SERVICE_UNAVAILABLE
- UPGRADE_PACKAGE_REJECTED
- UPGRADE_EXECUTION_CONFIRMATION_REQUIRED
- UPGRADE_EXECUTION_REJECTED
