# 报告文件管理接口

| 属性 | 内容 |
|---|---|
| 创建日期 | 2026-07-14 |
| 最后更新 | 2026-07-15 |
| 代码依据 | `server/routes/reports.js` |

## 1. 接口

| 方法 | 路径 | 权限 | 响应 |
|---|---|---|---|
| GET | `/api/reports` | 登录 | 自动同步后返回 `reports[]`；支持来源字段精确筛选 |
| GET | `/api/reports/:id/preview` | 登录 | PDF inline 或 UTF-8 文本流 |
| GET | `/api/reports/:id/download` | 登录 | attachment 文件流 |
| DELETE | `/api/reports/:id` | 管理员 | 删除实体、审计 JSON 和元数据 |
| GET | `/api/system-settings/report-storage` | 管理员 | 只读返回部署配置的 `reportStorageRoot`，并写入查看审计 |

报告对象：`id/name/reportType/sourceSessionId/sourceUserId/dataSourceId/mimeType/size/status/createdAt/updatedAt`。不返回服务器路径、存储名或配套审计文件名。

## 2. 自动同步契约

列表读取前扫描 `GAIOP_REPORTS_DIR` 中的 JSON。有效审计 JSON至少提供：

```json
{
  "reportId": "stable-id",
  "fileName": "report.pdf",
  "title": "巡检报告",
  "reportType": "inspection",
  "generatedAt": "2026-07-14T10:00:00Z",
  "sourceSessionId": "optional",
  "sourceUserId": "optional",
  "dataSourceId": "optional"
}
```

文件名必须是纯 basename 且实体位于报告根目录。格式错误、缺少 ID/文件名或指向目录外的 JSON 被忽略。

## 3. 错误码

| code | HTTP | 条件 |
|---|---:|---|
| `REPORT_NOT_FOUND` | 404 | 元数据不存在 |
| `REPORT_FILE_MISSING` | 404 | 实体缺失并标记 missing |
| `REPORT_PREVIEW_UNSUPPORTED` | 415 | 格式不支持预览 |
| `REPORT_STREAM_FAILED` | 500 | 文件流失败 |
| `REPORT_DELETE_FAILED` | 500 | 删除部分或全部失败 |

## 4. 一致性与限制

`GET /api/reports` 可选查询参数为 `sourceUserId`、`sourceSessionId`、`dataSourceId`，均为可组合的精确匹配。每个 `reports[]` 元素返回同名 camelCase 来源字段；缺失值为 `null`，由页面显示为“未记录”。

读取范围先于筛选生效：管理员可读取全部报告；非管理员只能读取 `sourceUserId` 精确等于当前登录用户 ID 的记录。旧报告的 `sourceUserId=null` 只对管理员可见。`GET /api/reports/:id/preview` 与 `GET /api/reports/:id/download` 使用同一规则，未授权时返回 `REPORT_NOT_FOUND`，避免通过 ID 探测报告是否存在；两种读取均写入 Admin 审计。

自动同步采用存储名冲突更新。删除涉及文件系统和 SQLite，不是完整跨资源事务；异常时可能需要刷新同步；不新增上传接口。`sourceUserId` 只接受 GAIOP 写入审计 JSON 的可信值，不由列表请求或文件名推断。Web 签名来源信封默认关闭，需完成真实 Gateway/Web 元数据透传联调后才可开启。
