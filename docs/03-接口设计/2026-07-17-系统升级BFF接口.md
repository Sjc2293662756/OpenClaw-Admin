# 系统升级 BFF 接口（第一阶段）

## 状态

2026-07-17 起，系统升级从占位页进入“只读服务联动”阶段。该阶段不上传包、不执行升级、不回滚，也不删除备份。

## 浏览器接口

GET /api/system-upgrade/overview

仅管理员可调用。Admin BFF 根据本地部署配置读取升级服务的 health、组件状态、最近十条任务和备份列表，再返回聚合结果。

返回字段：

- runtime.state：reachable、not-configured 或 unavailable；
- status：GAIOP 核心、GAIOP-Admin、Skill 和维护模式；
- tasks、backups：只读摘要。

浏览器不接触升级服务地址、内部身份令牌、服务器文件路径或升级包。

## 服务间边界

- Admin BFF 读取 GAIOP_UPGRADE_SERVICE_URL 和 GAIOP_UPGRADE_INTERNAL_TOKEN；
- BFF 调用升级服务时携带 X-GAIOP-Upgrade-Token 与派生的 X-GAIOP-Upgrade-Actor；
- 升级服务仅在配置内部令牌后强制验证该令牌；未配置时保留现有反向代理开发兼容模式；
- ISO 部署必须把升级服务限制在内部网络，令牌由部署侧安全存储提供，绝不提交至 Git。

## 后续接口

包上传、校验、执行、回滚、备份删除会另行设计：必须采用 BFF 流式传输、二次确认、操作审计和运行进度轮询，不能将浏览器直连到升级服务。
