# 认证与用户管理接口

| 属性 | 内容 |
|---|---|
| 创建日期 | 2026-07-11 |
| 最后更新 | 2026-07-15 |
| 代码依据 | `server/routes/auth.js`、`server/routes/users.js` |

## 1. 认证接口

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/api/auth/config` | 公开 | 返回认证是否启用 |
| POST | `/api/auth/login` | 公开 | 用户名密码登录 |
| POST | `/api/auth/logout` | 可匿名调用 | 删除当前 Token；有效会话记录审计 |
| GET | `/api/auth/check` | 登录 | 校验 Token 并返回当前用户 |

登录请求：

```json
{ "username": "example", "password": "<password>" }
```

成功响应：

```json
{
  "ok": true,
  "token": "<opaque-token>",
  "user": { "id": "...", "username": "example", "role": "standard" }
}
```

错误码：`LOGIN_INPUT_REQUIRED`、`INVALID_CREDENTIALS`。账号不存在、停用和密码错误使用同一错误，防止枚举。

## 2. 用户接口

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/api/users` | 登录 | 用户列表，不含密码 |
| POST | `/api/users` | 管理员 | 新增用户 |
| PUT | `/api/users/:id` | 管理员 | 修改描述、角色和状态；用户名不变 |
| POST | `/api/users/:id/reset-password` | 管理员 | 重置为系统默认密码并注销目标会话 |
| PUT | `/api/users/:id/password` | 本人或管理员 | 修改密码 |
| DELETE | `/api/users/:id` | 管理员 | 删除用户 |

### 新增用户

```json
{
  "username": "operator01",
  "password": "<initial-password>",
  "role": "standard",
  "description": "一线运维",
  "status": "active"
}
```

约束：用户名必填且不超过 64，忽略大小写唯一；密码至少 6 位；角色为 `basic/auditor/standard/admin`；状态为 `active/inactive`；描述不超过 500。

### 修改密码

本人修改：

```json
{ "currentPassword": "<current>", "newPassword": "<new>" }
```

管理员修改他人时不要求目标用户当前密码。成功后撤销目标用户除当前请求 Token 外的其他 Token；重置密码撤销全部目标用户 Token。

### 编辑用户

```json
{
  "description": "一线运维",
  "role": "standard",
  "status": "active"
}
```

描述最长 500；角色和状态使用既有枚举。当前登录管理员不能修改自身角色或将自身停用；最后一个激活管理员不能被降级或停用。角色或状态变化后撤销目标用户全部活动 Token，用户重新登录后获得新权限。

## 3. 主要错误码

| code | HTTP | 条件 |
|---|---:|---|
| `INVALID_USER_INPUT` | 400 | 字段缺失或格式错误 |
| `USERNAME_EXISTS` | 409 | 用户名重复 |
| `USER_NOT_FOUND` | 404 | 用户不存在 |
| `PASSWORD_TOO_SHORT` | 400 | 新密码少于 6 位 |
| `CURRENT_PASSWORD_INCORRECT` | 400 | 本人修改时旧密码错误 |
| `PERMISSION_DENIED` | 403 | 修改他人但非管理员 |
| `CURRENT_USER_DELETE_FORBIDDEN` | 400 | 删除当前登录用户 |
| `LAST_ADMIN_DELETE_FORBIDDEN` | 400 | 删除最后一个激活管理员 |
| `CURRENT_USER_SECURITY_UPDATE_FORBIDDEN` | 400 | 修改当前用户角色或将其停用 |
| `LAST_ADMIN_UPDATE_FORBIDDEN` | 400 | 降级或停用最后一个激活管理员 |

## 4. 审计与安全

登录、退出、创建、重置、修改和删除均记录审计。审计只写用户名、角色、状态等摘要，不写密码。默认重置密码是过渡机制，部署文档不得记录真实初始管理员密码。

## 5. 非原子与限制

会话存于进程内存，服务重启后失效；用户数据在 SQLite。当前没有用户名修改、服务端分页、失败锁定和持久化 Token。
