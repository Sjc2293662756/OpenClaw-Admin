# 认证与用户管理接口

| 属性 | 内容 |
|---|---|
| 创建日期 | 2026-07-11 |
| 最后更新 | 2026-08-31 |
| 代码依据 | `server/routes/auth.js`、`server/routes/users.js`、`server/routes/module-permissions.js` |

## 1. 认证接口

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/api/auth/config` | 公开 | 返回认证是否启用 |
| POST | `/api/auth/login` | 公开 | 用户名密码登录 |
| POST | `/api/auth/logout` | 可匿名调用 | 删除当前 Token；有效会话记录审计 |
| GET | `/api/auth/check` | 登录 | 校验 Token 并返回当前用户 |

登录请求：

```json
{ "username": "example", "password": "<password>" }
```

成功响应中的用户对象额外返回 `isInitialAdmin` 和 `mustChangePassword`：

```json
{
  "ok": true,
  "token": "<opaque-token>",
  "user": {
    "id": "...",
    "username": "example",
    "role": "standard",
    "isInitialAdmin": false,
    "mustChangePassword": false,
    "effectiveModules": { "dashboard": true, "alerts.records": true },
    "permissionVersion": 3
  }
}
```

错误码：`LOGIN_INPUT_REQUIRED`、`INVALID_CREDENTIALS`。账号不存在、停用、密码错误和临时锁定使用相同外部错误，防止枚举。同一用户名按大小写不敏感连续失败5次后锁定5分钟；到期自动解除，成功登录清空计数。

## 2. 用户接口

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/api/users` | 最终 `users` 模块允许 | 统一账户安全投影，不含密码、Token 或 `mustChangePassword`；basic/standard 可由个人 allow 获得只读访问 |
| POST | `/api/users` | 管理员 | 新增用户 |
| PUT | `/api/users/:id` | 管理员 | 修改描述、角色和状态；用户名不变 |
| POST | `/api/users/:id/reset-password` | 管理员层级检查 | 设置临时密码、标记首次改密并注销目标会话 |
| PUT | `/api/users/:id/password` | 本人 | 修改本人密码 |
| DELETE | `/api/users/:id` | 管理员 | 删除用户 |
| GET | `/api/module-permissions/catalog` | 登录 | 返回服务端固定模块目录 |
| GET | `/api/users/:id/module-permissions` | 初始管理员 | 返回目标用户默认/覆盖/最终投影 |
| PUT | `/api/users/:id/module-permissions` | 初始管理员 | 按 `expectedVersion` 原子替换全部覆盖 |
| DELETE | `/api/users/:id/module-permissions` | 初始管理员 | 删除全部覆盖并恢复角色默认 |

模块管理请求、投影、错误码和审计详见[2026-08-31-单用户模块权限管理接口](2026-08-31-单用户模块权限管理接口.md)。

### 新增用户

```json
{
  "username": "operator01",
  "password": "<initial-password>",
  "role": "standard",
  "description": "一线运维",
  "status": "active"
}
```

约束：用户名必填且不超过64，忽略大小写唯一；密码至少8位且同时包含英文字母和数字；角色为 `basic/auditor/standard/admin`；状态为 `active/inactive`；描述不超过500。普通管理员不能创建管理员，只有初始管理员可以。

### 重置密码

```json
{
  "temporaryPassword": "<temporary-password>",
  "confirmPassword": "<temporary-password>"
}
```

两次输入必须一致并符合密码规则。成功后服务端设置 `must_change_password=1`，撤销目标用户全部Token，不在响应或审计中返回临时密码。普通管理员不能重置管理员；初始管理员可重置其他管理员，但任何人都不能通过此接口重置初始管理员。

### 修改密码

本人修改：

```json
{ "currentPassword": "<current>", "newPassword": "<new>" }
```

仅允许本人调用并校验当前密码。成功后清除 `must_change_password`，撤销本人全部Token，响应 `reauthenticate: true`，客户端必须重新登录。其他用户密码只能通过重置接口处理。

### 编辑用户

```json
{
  "description": "一线运维",
  "role": "standard",
  "status": "active"
}
```

描述最长500；角色和状态使用既有枚举。管理员不能通过用户编辑接口修改自身账户，只能正常修改自己的密码；最后一个激活管理员不能被降级或停用。普通管理员只能编辑非管理员，不能将用户提升为管理员；初始管理员可管理其他管理员。初始管理员自身不能停用或降级。角色或状态变化后撤销目标用户全部活动Token。

被标记首次改密的Token只允许 `GET /api/auth/check`、`POST /api/auth/logout` 和本人 `PUT /api/users/:id/password`；其他受保护REST以及 `/api/rpc` 统一返回 `PASSWORD_CHANGE_REQUIRED`。

## 3. 主要错误码

| code | HTTP | 条件 |
|---|---:|---|
| `INVALID_USER_INPUT` | 400 | 字段缺失或格式错误 |
| `USERNAME_EXISTS` | 409 | 用户名重复 |
| `USER_NOT_FOUND` | 404 | 用户不存在 |
| `PASSWORD_POLICY_VIOLATION` | 400 | 密码不满足长度、英文字母和数字规则 |
| `PASSWORD_CONFIRMATION_MISMATCH` | 400 | 两次临时密码不一致 |
| `CURRENT_PASSWORD_INCORRECT` | 400 | 本人修改时旧密码错误 |
| `PERMISSION_DENIED` | 403 | 修改他人但非管理员 |
| `PASSWORD_CHANGE_REQUIRED` | 403 | 临时密码登录后尝试访问改密之外的受保护接口 |
| `ADMIN_MANAGEMENT_FORBIDDEN` | 403 | 普通管理员管理管理员或触碰初始管理员保护 |
| `CURRENT_USER_DELETE_FORBIDDEN` | 400 | 删除当前登录用户 |
| `LAST_ADMIN_DELETE_FORBIDDEN` | 400 | 删除最后一个激活管理员 |
| `CURRENT_USER_SECURITY_UPDATE_FORBIDDEN` | 400 | 修改当前用户角色或将其停用 |
| `LAST_ADMIN_UPDATE_FORBIDDEN` | 400 | 降级或停用最后一个激活管理员 |

## 4. 审计与安全

登录成功、失败、临时锁定、退出、创建、角色状态修改、重置、改密成功/失败和删除均记录审计。审计只写用户名、角色、状态和非敏感结果，不写密码、临时密码、Token或密码哈希。

## 5. 非原子与限制

会话和登录失败计数存于进程内存，服务重启后失效/清空；用户及首次改密、初始管理员标记存于SQLite。当前没有用户名修改、服务端分页、持久化Token或持久化失败锁定。
