# 环境与敏感配置接口

| 属性 | 内容 |
|---|---|
| 创建日期 | 2026-07-14 |
| 最后更新 | 2026-07-15 |
| 代码依据 | `server/routes/sensitive-config.js`、`sensitive-config-service.js` |

## 1. 接口

全部仅管理员。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/system-config/environment` | 读取配置元数据和非敏感值 |
| PUT | `/api/system-config/environment/:key` | 新增或覆盖配置 |
| DELETE | `/api/system-config/environment/:key` | 删除配置 |

## 2. 保存请求

```json
{
  "category": "integration",
  "description": "示例配置",
  "isSensitive": true,
  "value": "<secret>"
}
```

路径 `:key` 必须以大写字母开头，只含大写字母、数字、下划线，最长 128。类别为 `runtime/integration/security/certificate`；描述最长 300；值必须提供且最长 16384。

## 3. 返回与加密

敏感值返回：`key/category/description/isSensitive/valueConfigured/updatedAt`，不返回 `value`。非敏感值额外返回 `value`。敏感值使用 AES-256-GCM 保存；优先使用 `SENSITIVE_CONFIG_ENCRYPTION_KEY`，未配置时兼容回退 `DATA_SOURCE_ENCRYPTION_KEY`。

缺少加密密钥且保存敏感值时返回 `503 SENSITIVE_CONFIG_ENCRYPTION_KEY_MISSING`。其他错误：`INVALID_SENSITIVE_CONFIG_INPUT`、`SENSITIVE_CONFIG_SAVE_FAILED`、`SENSITIVE_CONFIG_NOT_FOUND`。

## 4. 生效语义

接口只保存 GAIOP 管理配置，不修改 `.env`，不调用操作系统，不自动重启管理服务或 Gateway。删除也只删除管理数据库记录。前端必须显示“已保存/已配置”，不能显示“运行时已生效”。

## 5. 后续安全要求

正式运行时消费应按配置键白名单实现，每个键定义消费者、默认值、校验、生效方式、重启需求和回滚；禁止将本接口扩展成任意环境变量编辑器。密钥轮换前必须支持旧密文解密与重新加密流程。
