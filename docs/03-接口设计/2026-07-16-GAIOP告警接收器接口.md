# GAIOP Syslog 告警接收器接口

| 属性 | 内容 |
|---|---|
| 创建日期 | 2026-07-16 |
| 状态 | 接收器接口、开关跨重启持久化与 Admin BFF 告警列表适配已实现；NAPM 发送端和浏览器端到端待联调 |
| 访问范围 | 仅 Admin BFF 与 GAIOP 同主机/私网部署接口，浏览器不可直连 |

## 1. 安全边界

接收器只监听部署指定的本机回环或受控私网地址。部署可提供内部认证值；认证值、日志路径、rsyslog 配置、原始 Syslog 和服务器地址均不返回浏览器或审计。

## 2. `GET /health`

返回：

```json
{
  "ok": true,
  "health": {
    "state": "healthy",
    "enabled": true,
    "lastReceivedAt": null,
    "lastErrorCode": null
  }
}
```

`state` 只表示接收器进程和日志监听状态；`lastReceivedAt=null` 表示尚未收到可解析的新告警，不能解释为 NAPM 已联通。

## 3. `PUT /config`

请求体仅支持：

```json
{ "enabled": true }
```

它控制告警事件是否写入本地持久化存储，并将启用状态原子写入接收器受控状态目录，服务重启后恢复该状态。不安装软件、不修改 rsyslog、端口、防火墙或 NAPM 发送端。非法值返回 `400 ALERT_RECEIVER_CONFIG_INVALID`。

## 4. `GET /alerts`

支持 `page`、`pageSize`、`severity`、`category`、`keyword`，返回规范化事件、`availableCount` 和 `hasMore`。浏览器继续只调用既有 `/api/alerts`；Admin BFF 将本接口映射为稳定的页面模型，浏览器不得直接调用本接口。
