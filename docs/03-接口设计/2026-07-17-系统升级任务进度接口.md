# 系统升级任务进度接口

## 接口

GET /api/system-upgrade/tasks/:taskId

仅管理员可访问。Admin BFF 查询升级服务的任务详情，并只返回页面显示进度所需字段：

- 任务类型、组件、版本、状态；
- 进度百分比、当前步骤、预计剩余秒数；
- 预检、备份、替换、重载、健康检查、收尾各步骤的状态和受限长度说明；
- 任务错误摘要、开始和结束时间。

不返回升级包位置、备份目录、安装目录、内部地址、身份令牌或服务端原始数据库字段。

## 轮询规则

- 用户点击任务详情，或确认执行后，页面首次读取详情；
- 仅当状态为 running 或 rolling_back 时每 3 秒轮询一次；
- 成功、失败、回滚完成、读取失败或离开页面时立即停止；
- 轮询为只读查询，不执行、重试或变更升级任务。

## 验收

1. 非管理员无法读取任务详情。
2. 无效或不存在任务返回受控错误码。
3. BFF 不泄露任务包或备份路径。
4. 运行中任务显示进度和步骤；任务终态后页面不继续轮询。
