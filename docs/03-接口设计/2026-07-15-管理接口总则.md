# GAIOP 管理接口总则

| 属性 | 内容 |
|---|---|
| 创建日期 | 2026-07-15 |
| 状态 | 当前接口基线 |

## 1. 边界

浏览器只访问 GAIOP 管理服务。管理服务负责认证、RBAC、审计、配置存储和 Gateway 代理；浏览器不直接访问 NAPM，也不持有 NAPM 密码或 Gateway Token。

## 2. 认证

除明确标记为公开的接口外，请求头使用：

```http
Authorization: Bearer <session-token>
Content-Type: application/json
```

Token 是不透明值，不写入 URL。认证失效统一由前端清理本地状态并进入登录流程。

## 3. 统一响应

成功：

```json
{ "ok": true, "...": "业务字段" }
```

失败：

```json
{ "ok": false, "error": "面向用户的消息", "code": "STABLE_ERROR_CODE" }
```

HTTP 状态：`400` 输入/状态冲突，`401` 未认证，`403` 无权限，`404` 资源不存在，`409` 唯一性冲突，`410` 遗留功能停用，`415` 不支持格式，`503` 依赖或必要配置不可用，`500` 未分类服务错误。

## 4. 权限和审计

- 读接口至少要求登录；审计读取只允许 auditor/admin。
- 管理写接口默认仅 admin；标准用户写能力通过明确 REST 或 RPC 白名单授予。
- 所有安全和业务写操作应记录操作者、角色、动作、对象、结果和时间；不得记录凭据。
- 页面隐藏、按钮禁用和前端路由不是安全控制。

## 6. 兼容与停用接口

- `/api/files/*`：`410 LEGACY_FILE_BROWSER_DISABLED`。
- `/api/config`：`410 LEGACY_ENV_CONFIG_DISABLED`。
- `/api/hermes*`：停用产品模式，不作为 GAIOP 正式接口。
- 遗留终端、桌面、备份代码虽仍在服务端，不属于正式产品接口，不得由新页面调用。
