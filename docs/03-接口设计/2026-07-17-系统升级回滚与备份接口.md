# 系统升级回滚与备份接口

## 浏览器接口

| 方法 | 路径 | 确认词 |
|---|---|---|
| POST | /api/system-upgrade/backups/:backupId/rollback | ROLLBACK |
| DELETE | /api/system-upgrade/backups/:backupId | DELETE |

仅管理员可调用。确认词不正确时 BFF 不请求升级服务。

## 回滚范围

当前仅开放 Skill 组件的人工回滚。核心和前端组件需要组件专用的重载、健康检查和失败恢复流程，现阶段后端会明确拒绝，页面不会伪称已支持。

回滚请求从受控备份 ID 派生组件和目标版本，浏览器不能提交服务器路径、操作者或任意目标目录。服务接受后返回新的回滚任务 ID，页面复用任务进度轮询。

## 删除备份

删除仅针对升级服务登记的备份 ID。升级服务会验证备份目录位于受控 backupRoot 内，拒绝删除该目录之外的任意路径；成功后才删除物理目录和数据库记录。

总览和接口响应不返回 backup_path、任务包路径、内部地址或令牌。
