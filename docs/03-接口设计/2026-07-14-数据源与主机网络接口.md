## 1. 数据源接口

所有数据源接口要求 `DATA_SOURCE_ENCRYPTION_KEY` 可用，否则返回 `503 DATA_SOURCE_ENCRYPTION_KEY_MISSING`，包括列表读取；这是为了避免无法稳定处理加密凭据。

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/api/data-sources` | 登录 | 列表和运行时桥接状态 |
| POST | `/api/data-sources` | 管理员 | 新增，密码必填 |
| PUT | `/api/data-sources/:id` | 管理员 | 编辑，密码留空表示不变 |
| DELETE | `/api/data-sources/:id` | 管理员 | 删除非运行源 |
| POST | `/api/data-sources/:id/test` | 管理员 | 测试 HTTPS、认证和接口 |
| POST | `/api/data-sources/:id/activate` | 管理员 | 设为唯一运行数据源并写桥接文件 |

### 输入字段

| 字段 | 类型 | 规则 |
|---|---|---|
| `ip` | string | 合法 IPv4/IPv6，不输入 URL |
| `description` | string | 可空，最长 300 |
| `type` | enum | `local` 或 `remote` |
| `username` | string | 必填，最长 128 |
| `password` | string | 新增必填，最长 1024；编辑省略/空策略以页面实现为准 |
| `status` | enum | 用户输入仅 `untested` 或 `disabled` |

列表公开字段：`id/ip/description/type/username/status/isActive/passwordConfigured/createdAt/updatedAt/lastTestedAt/lastTestMessage`。不返回密码、密文、TLS 内部模式或运行时文件路径。

### 连接测试

目标固定为 `https://<IP>/webservice/NetInside?type=applianceInfo&json=true`，服务端附带认证并设置 15 秒超时。严格 TLS 遇到 NAPM 自签名证书时，仅对该数据源自动重试兼容模式；成功后保存 `napm_self_signed`，不全局关闭校验。

测试成功响应中的 `result` 包含 `ok/durationMs/message/tlsMode/compatibilityMode/testedAt`。测试失败可能仍返回 HTTP 200 且 `result.ok=false`，表示请求流程正常但目标不可用；路由内部异常返回 `DATA_SOURCE_TEST_FAILED`。

### 启用和运行时

启用在数据库事务中先清除旧 `is_active`、设置新运行源并写运行时桥接。生产未配置 `GAIOP_ACTIVE_DATA_SOURCE_FILE` 时返回 `503 DATA_SOURCE_RUNTIME_TARGET_MISSING`。GAIOP 智能体核心必须配置为同一绝对路径；旧 `GAIOP_DATA_SOURCE_RUNTIME_FILE` 仅作为兼容别名。桥接文件包含明文运行凭据，使用临时文件+原子重命名并尝试权限 0600；绝不返回浏览器或提交仓库。

### 主要错误码

`INVALID_DATA_SOURCE_INPUT`、`DATA_SOURCE_NOT_FOUND`、`DATA_SOURCE_DISABLED`、`ACTIVE_DATA_SOURCE_CANNOT_DISABLE`、`ACTIVE_DATA_SOURCE_CANNOT_DELETE`、`DATA_SOURCE_CREATE_FAILED`、`DATA_SOURCE_UPDATE_FAILED`、`DATA_SOURCE_TEST_FAILED`、`DATA_SOURCE_RUNTIME_TARGET_MISSING`、`DATA_SOURCE_ACTIVATION_FAILED`。

## 2. 已下线接口与部署边界（2026-07-16）

`/api/host-network-config` 已下线，不再提供读取或保存主机、网络、NTP、时区和语言的接口。服务器网络与部署参数由部署环境维护，不属于 GAIOP 管理控制台的业务配置。

界面语言改由浏览器本地偏好保存；数据源启用仍会写入 GAIOP Skills 使用的受控运行时桥接，两者生效语义不同。
