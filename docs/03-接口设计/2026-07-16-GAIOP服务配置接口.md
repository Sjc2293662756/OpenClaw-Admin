# GAIOP 服务配置接口

| 属性 | 内容 |
|---|---|
| 创建日期 | 2026-07-16 |
| 状态 | 本地 BFF 已实现；237 Gateway 真实鉴权待联调 |
| 页面 | `系统配置 → GAIOP 服务配置` |

## 1. 目的与边界

该接口只配置 Admin BFF 到 GAIOP 服务的受控 WebSocket 连接，用于本地 SSH 隧道或部署环境内部网络连接。它不修改远端 GAIOP 服务、NAPM、Syslog、服务器网络或防火墙。

浏览器不直接连接服务，不获得访问令牌、认证密码、SSH 凭据、私钥或远端配置文件内容。

## 2. 接口

### `GET /api/system-config/gaiop-service`

- 权限：`admin`
- 返回：接入地址、访问令牌是否已配置、当前 BFF 连接状态。
- 不返回：访问令牌、认证密码、SSH 凭据、私钥、远端地址映射细节。

```json
{
  "ok": true,
  "service": {
    "endpoint": "ws://127.0.0.1:3003",
    "accessTokenConfigured": true,
    "state": "disconnected"
  }
}
```

### `PUT /api/system-config/gaiop-service`

- 权限：`admin`
- 请求字段：
  - `endpoint`：必填，`ws://` 或 `wss://` 服务接入地址；不能包含账号、密码、查询参数或片段。
  - `accessToken`：可选；提供非空值时更新访问令牌，留空或省略时保持已有令牌。
- 行为：BFF 在本机受控 `.env` 中保存连接参数，替换当前 Gateway 客户端并发起重新连接。
- 审计：仅记录“令牌已更新/保持不变”和重新连接操作，不记录令牌值。

## 3. 验收

1. 非管理员访问或保存均返回 `403`。
2. 读取接口和页面不回显令牌、密码、SSH 凭据、私钥或远端配置。
3. 只允许合法的 `ws://` 或 `wss://` 地址；无账号、查询参数或片段。
4. 保存后 BFF 使用新的连接参数重连；会话设置路由读取当前 Gateway 实例，不保留旧实例引用。
5. 本地 237 联调以 BFF 连接状态、工作台创建会话和发送消息为准；仅隧道端口可达不视为鉴权成功。
6. 工作台必须区分首次连接、重新连接和连接失败；初始 Gateway 未连接时不得永久停留在“正在连接”，失败后提供手动重新连接入口。
7. 保存连接配置或替换 Gateway 客户端时，旧客户端必须终止自动重连并释放 WebSocket；不得因重复保存配置积累后台连接或产生相互冲突的状态事件。

## 4. 开发与部署地址

| 场景 | 服务接入地址 | 是否需要 SSH 隧道 |
|---|---|---|
| 本机开发、目标为 237 | `ws://127.0.0.1:3003` | 需要；使用根目录 `连接237GAIOP服务.cmd` 或完整本地启动器建立 `3003 → 237:18789` 转发；隧道进程支持断线自动重连 |
| Admin BFF 与 Gateway 同部署在 237 | `ws://127.0.0.1:18789` | 不需要；二者通过服务器本机回环连接 |

237 当前 Gateway 由用户级 `openclaw-gateway.service` 运行。服务地址和令牌由此页面保存到本机 BFF 的受控配置；若服务返回认证不匹配，必须以该运行服务的实际认证配置为准。修改远端认证配置或重启远端服务属于部署变更，须单独授权并在联调阶段执行。
