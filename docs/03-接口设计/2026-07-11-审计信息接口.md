## 1. 查询

```http
GET /api/audit-logs?limit=100&page=1&pageSize=100&maxResults=200&from=...&to=...
Authorization: Bearer <token>
```

权限：`auditor`、`admin`。保留 `limit=1..200`（默认100）的旧契约；未提供 `page`/`pageSize` 时等价于第1页。查询参数均在服务端执行：`from`、`to`（Unix 毫秒或 ISO 时间）、`username`、`role`、`category`、`result`、`source`、`errorCode`、`keyword`、`page`、`pageSize` 和 `maxResults`。`pageSize` 最大200；`maxResults` 缺失或非法时为200，最大3000且不小于 `pageSize`。

响应：

```json
{
  "ok": true,
  "logs": [
    {
      "id": "...",
      "actorUserId": "user-id-or-null",
      "username": "admin",
      "role": "admin",
      "action": "保存会话设置",
      "target": "系统设置",
      "detail": "不含敏感值的摘要",
      "createdAt": 1780000000000,
      "category": "authorization",
      "result": "denied",
      "source": "rpc",
      "restMethod": "POST",
      "restPath": "/api/rpc",
      "rpcMethod": "config.set",
      "errorCode": "BASIC_READ_ONLY",
      "requestId": "服务器生成的UUID",
      "sourceAddress": "服务端套接字确认的地址"
    }
  ],
  "pagination": { "page": 1, "pageSize": 100, "total": 453, "browseTotal": 200, "maxResults": 200, "totalPages": 2 },
  "summary": { "total": 42, "success": 30, "failed": 4, "denied": 7, "unclassified": 1 }
}
```

`actorUserId` 仅用于审计详情的操作用户标识展示；历史缺失值返回 `null`。`unclassified` 是结果为空或非三种结构化结果的历史记录数，保证 `total = success + failed + denied + unclassified`。旧记录的新字段保持空值，接口不猜测回填。

`pagination.total` 与 `summary` 永远表示完整筛选条件的真实结果；`browseTotal = min(total, maxResults)`，`totalPages` 和本次 `logs` 仅覆盖 `browseTotal` 范围。请求页超过TOP可浏览范围时服务端回落到最后可浏览页，避免直接调用接口绕过TOP分页边界。

## 2. 权限与错误

未登录返回 401；基础或标准用户返回 `403 PERMISSION_DENIED`。排序固定为 `createdAt DESC, id DESC`，避免同毫秒记录分页漂移。当前不提供游标或导出。

## 3. 写入规则

审计写入由服务端业务路由调用兼容的 `recordAudit` 或结构化写入器，浏览器没有通用“新增审计”接口，防止伪造。新记录不保存密码、Token、Cookie、密钥、完整请求体、查询参数原文、完整 RPC 参数、聊天内容、报告正文或敏感配置。来源地址只取服务端套接字可确认的值，不信任 `X-Forwarded-For`。

已登录 REST 403、Gateway RPC 权限拒绝、管理员未登记 RPC，以及会话/报告/媒体归属隐藏 404 均写入 `denied`。匿名 401 和遗留入口 `410 ENDPOINT_RETIRED` 采用有界内存限频；登录失败、锁定和 `PASSWORD_CHANGE_REQUIRED` 保持认证审计。

## 4. 后续契约

审计页面已使用本接口完成服务端时间范围、筛选、分页、总数和五项汇总查询；接口读取本身不新增“查看审计”记录。本阶段仍不增加导出、删除、保留策略、防篡改签名、WORM 或 SIEM。
