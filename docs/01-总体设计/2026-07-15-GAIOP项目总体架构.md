## 1. 产品定位

观枢 GAIOP 是面向运维人员和管理人员的智能运维分析与智能体管理平台。它以对话为主要业务入口，调用 NAPM 数据和 GAIOP Skills 完成告警研判、性能分析、数据包分析、巡检和报告生成；管理控制台负责模型、Skills、会话、任务、频道、用户、权限、配置和运行状态管理。

GAIOP 不重复建设 NAPM 已成熟的全流量监控、拓扑、深度指标和专业报表页面。

| GAIOP 负责 | NAPM 负责 |
|---|---|
| 运维分析对话、智能体编排和结果解释 | 原始流量、性能、对象、告警和专业分析数据 |
| 模型、Skills、任务、频道和智能体管理 | 数据采集、存储和 WebService 接口 |
| 用户、权限、审计、系统设置和系统配置 | NAPM 自身的用户和产品配置 |
| 告警通知入口、报告产物和分析闭环 | 告警产生及原始详情 |

## 2. 产品原则

1. 用户可见界面统一使用“NetInside 观枢 GAIOP”，不出现原开源后台或底层框架产品名。
2. 登录后默认进入对话工作台；管理控制台是平级的第二工作空间。
3. 在线对话只用于智能运维分析，不划分普通聊天、报告、数据包等独立聊天模式。
4. 最终使用 HTTPS 443 作为唯一公网入口；内部端口仅用于同机或内网通信。
5. NAPM 当前使用一个运行数据源，数据结构预留多个数据源和显式切换能力。
6. Hermes 全部模块、远程终端、远程桌面、虚拟公司和数据备份从正式产品隐藏，源码暂时保留。
7. 报告文件管理只能访问受控报告目录，不提供全局文件系统管理。
8. “系统设置”管理日常使用策略；“系统配置”管理部署、集成与安全配置。

## 3. 逻辑架构

```text
浏览器
  ├─ 对话工作台
  └─ 管理控制台
        ↓ HTTPS / REST / RPC
GAIOP-Admin 管理服务（BFF）
  ├─ 登录会话、RBAC、用户、审计
  ├─ 数据源、主机网络、敏感配置、报告、会话设置
  └─ Gateway RPC 代理与权限控制
        ↓ 本机回环或私网 WebSocket
GAIOP 智能体服务
  ├─ 会话上下文、模型、任务、频道、记忆、多智能体
  └─ NAPM Skills、告警与报告生成
        ↓ HTTPS WebService / Syslog
NAPM 数据源
```

## 4. 物理代码结构

```text
GAIOP/
├─ GAIOP-Admin/
│  ├─ src/                     # Vue 3 前端
│  │  ├─ views/                # 页面
│  │  ├─ stores/               # 前端状态与业务调用
│  │  ├─ api/                  # REST/RPC 客户端与类型
│  │  └─ router/               # 正式路由
│  ├─ server/                  # Express 管理服务/BFF
│  │  ├─ routes/               # 已拆分的管理 REST 路由
│  │  ├─ lib/                  # 权限、响应、敏感数据、会话策略
│  │  └─ database.js           # SQLite 数据结构
│  ├─ data/                    # 本地管理数据库、报告目录
│  └─ docs/                    # 本文档体系
├─ skills/                     # NAPM 查询、诊断、数据包和报告 Skills
├─ config/                     # GAIOP 业务与运行配置
└─ napm-openclaw-plugin.remote.js # 智能体插件内部实现文件
```

两个实际目录不是互相替代关系：`GAIOP-Admin` 负责页面、管理接口、用户权限和 Gateway 代理；`GAIOP` 负责插件、Skills、NAPM 查询和报告生成。它们通过内部 Gateway、活动数据源文件和报告目录共同组成一个产品。逐项映射见[GAIOP 与 GAIOP-Admin 职责和集成关系](2026-07-15-GAIOP与GAIOP-Admin职责和集成关系.md)。

内部代码、环境变量或协议中仍存在历史技术名称，当前允许作为兼容实现保留，但不得在用户界面展示。后续重命名必须评估配置兼容性，不能只做字符串替换。

## 5. 双工作空间

| 工作空间 | 路由 | 定位 | 核心功能 |
|---|---|---|---|
| 对话工作台 | `/workspace` | 默认业务入口 | 新对话、历史会话、分析输入、流式结果、用户菜单 |
| 管理控制台 | `/` 及子路由 | 管理与配置入口 | 仪表盘、智能体管理、平台管理、系统维护 |

工作空间通过完整页面跳转切换，不采用弹窗覆盖或在控制台内容区嵌套对话。这样可以保留对话的专注体验，也能让后台菜单保持稳定。

### 系统设置

- 基本设置：框架保留。
- 会话设置：登录有效期、管理端空闲超时、外部渠道上下文空闲重置、历史保留策略。
- 报告与文件设置：框架保留。
- 界面偏好：语言切换与主题切换，均为当前浏览器本地偏好。

### 系统配置

- 数据源管理：NAPM 地址、账号、加密密码、测试、运行数据源切换。
- 告警接入与转发：框架保留，告警阶段暂缓。
- 环境与敏感配置：加密存储和脱敏显示；尚未全部接入运行时消费者。

## 7. 认证、权限与审计

角色为基础用户、审计用户、标准用户、管理员。前端负责显示禁用状态和原因，服务端是最终安全边界。

| 角色 | 核心权限 |
|---|---|
| 基础用户 | 查看已授权页面；不能对话或修改 |
| 审计用户 | 基础查看 + 审计日志；不能修改 |
| 标准用户 | 对话、会话日常操作、任务、Skills 等常规功能 |
| 管理员 | 用户、数据源、安全配置及全部管理能力 |

当前审计已持久化到 SQLite，覆盖登录、用户、数据源、主机网络、敏感配置、报告删除和会话设置等自建写操作；Gateway 内部所有操作尚未形成完整统一审计。

## 8. 数据与配置边界

| 数据 | 权威来源 | 说明 |
|---|---|---|
| 用户、审计、系统配置元数据 | `GAIOP-Admin/data/wizard.db` | 管理服务 SQLite |
| 对话、模型、Skills、任务、记忆 | GAIOP Gateway | 通过受控 RPC 访问 |
| NAPM 凭据 | SQLite 加密字段 | 不向浏览器返回明文 |
| 当前运行数据源 | 受控运行时桥接文件 | 由管理员显式启用后写入 |
| 报告文件 | `GAIOP_REPORTS_DIR` | 管理服务和报告 Skill 共享受控目录 |
| 环境与敏感配置 | SQLite 加密/普通字段 | 当前主要是管理配置，不等于自动修改 `.env` |

## 9. 会话策略

- 管理平台登录会话：默认 24 小时，可配置管理端空闲退出。
- 外部消息渠道：默认连续 30 分钟无用户消息，下一条消息开始新分析上下文。
- GAIOP Web 对话工作台：不强制自动跳转或新建会话；用户可打开旧历史继续分析。渠道级超长空闲窗口是待 BFF/Gateway 联调验证的目标策略，当前浏览器使用默认会话路由。
- 历史保留天数目前只保存策略，不执行自动删除。

## 10. 部署目标

生产形态对用户表现为一个 GAIOP 产品和一个地址：

```text
https://<GAIOP主机>/          → 前端静态资源
https://<GAIOP主机>/api/*     → 管理服务
内部回环 WebSocket            → GAIOP Gateway
```

GAIOP 前端、管理服务和智能体服务通常部署在同一台主机或同一受控私网环境，因此用户无需配置“GAIOP 服务 IP”。NAPM 是外部业务数据源，需要独立配置。

## 11. 已确认与待设计

已确认：双工作空间、菜单框架、四类角色、系统设置/系统配置拆分、受控报告目录、单运行数据源、443 统一入口、外部渠道会话空闲策略。

待具体模块开发时设计：告警数据结构与 Syslog 协议、报告保留与用户隔离、系统升级包规范、多数据源绑定/切换策略、主机网络是否实际作用于操作系统、环境配置的运行时生效与重启机制。

这些待设计项不影响当前总体框架，不能在未确认前写成已实现能力。
