# GAIOP 产品定位与前端改造决策

| 属性 | 内容 |
|---|---|
| 形成日期 | 2026-07-11 |
| 最后更新 | 2026-07-15 |
| 状态 | 已确认决策 |

## 1. 改造目标

以原开源管理前端为技术框架，建设 NetInside 自有的“观枢 GAIOP 智能运维分析平台”。保留成熟的智能体管理能力，通过品牌、入口、登录、工作空间、权限、系统配置和业务边界改造，使其成为 GAIOP 的正式前端，而不是展示底层框架的通用管理工具。

## 2. 已确认决策

- 公司：北京网深科技有限公司，英文品牌 NetInside。
- 产品全名：NetInside 观枢 GAIOP 智能运维分析平台；简称观枢 GAIOP / GAIOP。
- 欢迎页采用绿色 NetInside 视觉，提供“开始对话”和“配置管理”两个入口。
- 登录只使用用户名和密码，不提供注册、找回密码、手机号或二维码。
- “开始对话”登录后进入对话工作台；“配置管理”进入管理控制台。
- 退出登录统一返回欢迎页。
- 用户界面不展示原项目、底层框架或 Hermes 品牌。
- 原主要智能体管理模块保留；不建设 NAPM 已有的专业监控大屏。

## 3. 保留、隐藏与改造

| 类别 | 模块 |
|---|---|
| 保留并逐步产品化 | 仪表盘、会话、记忆、任务、模型、频道、Skills、系统监视器、多智能体、智能体工坊 |
| 改造 | 在线对话→独立对话工作台；文件浏览器→报告文件管理；数据备份语义→系统升级 |
| 新增 | 用户管理、审计信息、告警通知、系统配置分区 |
| 隐藏并保留源码 | Hermes、远程终端、远程桌面、虚拟公司、数据备份 |
