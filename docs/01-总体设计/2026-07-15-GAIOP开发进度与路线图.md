## 3. 已完成阶段

### 阶段 A：架构与菜单收口——已完成

- 品牌、欢迎页、登录页和双工作空间建立。
- 正式路由隐藏 Hermes、远程终端、远程桌面、虚拟公司、数据备份。
- 在线对话从管理菜单移出，成为独立默认工作台。
- 系统设置和系统配置拆分；重复入口和底层连接表单收口。

### 阶段 B：管理接口和安全边界——基础版本已完成

- 认证、用户、审计、数据源、主机网络、敏感配置、报告和会话设置拆分为独立路由。
- 建立统一响应、错误码、服务端角色校验和非管理员敏感字段掩码。
- 标准用户 RPC 白名单与管理员安全配置边界形成。
- 旧全局文件接口和旧 Web 环境配置接口停用。

### 阶段 C：系统配置闭环——部分完成

- 数据源真实测试、数据源级自签名兼容和运行时桥接已完成本地验证；2026-07-15 曾以实际 `topValues` NAPM Skill 调用验证运行时消费者，页面、BFF 状态与日志均不返回桥接路径或凭据。该历史验证不等于 237/ISO 已完成唯一运行源迁移，也不等于所有入口均已禁止无活动数据源查询。
- 主机网络配置和环境敏感配置已保存到管理数据库。
- 会话保持策略已接入 Gateway 配置。
- 告警正式接收基础已完成，转发规则仍不在当前告警模块；环境配置运行时消费者尚未逐项实现。

## 4. 当前优先级

### P0：阶段收口与安全基线

1. 完成本轮代码、测试、文档和个人分支提交，保持原 GAIOP 用户工作树只读。
2. 为 Gateway 当前安全审计项制定方案：开放群策略与高权限工具组合、非回环监听认证限速、未固定插件版本；任何 237 修改必须另行获得用户授权。
3. 继续执行四角色直接接口与数据隔离验收，不以页面隐藏代替服务端权限。
4. 以[运行数据源查询边界与迁移规划](../04-公共设计/2026-07-21-运行数据源查询边界与迁移规划.md)为准，先完成活动源前置校验、旧回退清退和分入口验收，再把数据源运行时能力标记为部署闭环。

安全整改的分阶段目标、审批前置项、备份/回滚和验收证据见[安全风险整改与回滚方案](../05-部署运维/2026-07-20-安全风险整改与回滚方案.md)。该方案当前仅为本地设计，尚未对 237 或 ISO 应用任何配置。

### P1：ISO 可重复构建与冻结

1. 冻结 Gateway、飞书、钉钉、企业微信及 GAIOP/Admin 的精确版本和校验值。
2. 把频道 peer 依赖、插件索引刷新、全频道检查和失败回滚纳入构建/升级事务。
3. 确认服务账户、Node 路径、443 证书、持久化目录、备份介质、密钥托管和数据保留周期。
4. 在克隆/准生产环境完成冷启动、断网重连、备份恢复和失败升级演练后再冻结 ISO。

### P2：跨端部署联调

1. 验证 Web/Gateway 会话归属、历史无归属会话迁移和外部频道会话隔离。
2. 开启并验证报告来源签名、Gateway metadata 透传和共享报告卷。
3. 决定告警保留期、容量上限、清理/备份任务及 JSONL 是否迁移 SQLite 或其他事件数据库。
4. 使用真实升级包验证核心、前端、Skill 和频道插件升级/回滚；没有可验收升级包时不伪造成功状态。

### P3：产品深化

- 多 NAPM 数据源与智能体/租户绑定。
- 多智能体与智能体工坊职责收口。
- 报告保留、容量和自动清理。
- 模型、任务、记忆、Skills 的逐操作权限与审计深化。

## 5. 最新规划检查结论

当前总体方向合理：GAIOP 是“对话业务工作台 + 智能体管理后台”，而不是第二套 NAPM。系统设置/系统配置拆分、受控报告目录、独立告警模块、443 单入口和 Web 工作台自主选择历史会话都符合产品定位。

需要继续注意的结构问题：

1. 主机与网络配置已于 2026-07-16 下线；服务器网络、域名、DNS、NTP 和时区只由部署环境维护，界面语言归“界面偏好”。
2. “环境与敏感配置”不能成为任意环境变量编辑器。正式接入时应使用白名单配置项，并明确保存后是即时生效、重连、重启或仅供部署使用。
3. Web 工作台已完成本地会话归属隔离，报告正式归档也已完成本地双端代码；外部频道会话隔离、历史迁移和报告真实 Gateway/Web 来源透传仍待部署联调，这是多人使用前的核心风险。
4. 多智能体和智能体工坊当前管理同类对象，后续必须确定一个偏资源管理、一个偏场景编排，或合并。
5. 运行时仍使用部分历史内部环境变量和实现文件名；只要不对用户展示可以暂留，重命名应单独做兼容迁移。

## 6. 下一阶段完成标准

- 文档和实际路由、字段、权限、数据库一致。
- 关键自建接口具备正常、非法输入、无权限和依赖失败测试。
- 多用户会话与报告数据范围在真实 Gateway/共享卷中完成隔离验收。
- ISO 候选环境可通过一个 443 地址访问登录、对话和管理控制台，并通过重启与恢复测试。
- 数据源切换后 GAIOP Skills 实际读取对应 NAPM，凭据不出现在页面、日志和仓库。
