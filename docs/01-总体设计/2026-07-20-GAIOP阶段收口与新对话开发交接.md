## 1. 一句话理解系统

GAIOP 是一套智能运维产品，不是两个独立系统：

```text
GAIOP-Admin 前端
→ GAIOP-Admin BFF（权限、审计、配置、浏览器安全边界）
→ GAIOP Gateway（会话、模型、频道、任务、插件运行）
→ GAIOP Skills/业务插件
→ NAPM 数据源
```

浏览器不直接持有 Gateway Token，不直连服务器文件或内部告警接口。`GAIOP-Admin/server` 虽与前端同仓库交付，但它是服务端 BFF；涉及权限、凭据、Gateway RPC、报告或告警时不能只改 Vue 页面。

## 3. 当前本地运行链路

当前标准链路：

```text
浏览器 http://127.0.0.1:3002
→ Admin BFF http://127.0.0.1:3000
→ SSH 隧道 127.0.0.1:3003
→ 237 Gateway 127.0.0.1:18789
→ GAIOP Skills
→ NAPM 238

Admin BFF
→ SSH 隧道 127.0.0.1:3004
→ 237 Syslog 接收器 127.0.0.1:19090
```

常用入口：

- 欢迎页：`http://127.0.0.1:3002/welcome`
- 对话工作台：`http://127.0.0.1:3002/workspace`
- BFF 健康：`http://127.0.0.1:3000/api/health`
- GAIOP 服务配置填写：`ws://127.0.0.1:3003`

根目录脚本：

- `启动GAIOP本地开发环境.cmd`：启动/复用 3003、3004 隧道，再启动本地 BFF 与前端；它会访问 237。
- `连接237GAIOP服务.cmd`：只启动 3003/3004 SSH 隧道。
- `Start-Gateway237Tunnel.cmd`：兼容入口。

连接信息保存在本机用户作用域的加密文件 `%LOCALAPPDATA%\GAIOP\alert-syslog-connection.clixml`。脚本首次运行会由用户交互输入；后续从本机安全存储读取。不得读取、打印、复制、上传或提交其中的主机账号和密码，也不得输出 `.env` 中的 Token。

## 4. 237 操作授权与记录规则

237、NAPM 238 和旧服务器 236 都不是开发代理可以自由操作的本地环境。

1. 每一次由开发代理发起的 237 SSH 连接、隧道、只读查询、日志查看、文件修改、插件安装、配置写入、服务重启、部署、防火墙或 rsyslog 操作，都必须先得到用户针对该次操作的明确授权。
2. 用户本人双击本地启动/连接脚本，不等于自动授权开发代理继续执行服务器命令。
3. 获授权后先做只读预检，说明准备执行的命令、影响范围、备份和回滚，再做写操作。
4. 服务器写操作前必须在受保护目录备份；不打印备份中的频道凭据、Token 或密钥。
5. 操作完成后必须在 `GAIOP-Admin/docs/05-部署运维` 记录时间、现象、根因、原始非敏感错误、诊断命令、变更命令、验证结果、回滚方式和未完成项。
6. 未经明确授权，不部署、不重启、不改服务器配置；本地代码完成不等于 237 或客户环境已经生效。

## 6. 频道运行基线与故障教训

237 当前已核验组合：

| 组件 | 版本/状态 |
|---|---|
| Gateway | OpenClaw `2026.5.4` |
| 飞书 | `@larksuite/openclaw-lark@2026.5.20`，39 个工具契约，`loaded/running/works` |
| 企业微信 | `@wecom/wecom-openclaw-plugin@20206.7.201`，`loaded/running/works` |
| 钉钉 | `@dingtalk-real-ai/dingtalk-connector@0.8.23`，`loaded/running/connected`；CLI 深探针可能显示失败，但真实消息正常 |

关键教训：在共享 `~/.openclaw/npm/node_modules` 安装或升级一个插件会重建依赖树，可能清除其他插件的 `openclaw` peer 链接。2026-07-17 安装钉钉后企业微信因此加载失败；2026-07-20 升级飞书时同一行为再次影响企业微信和钉钉。

以后升级任一频道插件必须：

```text
冻结精确版本与兼容矩阵
→ 备份配置、插件目录、插件索引和依赖链接
→ 版本化临时目录安装
→ 校验全部交付插件的 peerDependencies 与入口
→ 切换并刷新插件索引
→ 重启 Gateway
→ 检查全部插件、全部已启用频道和真实消息
→ 任一失败整体回滚并再次验证
```

当前系统升级模块尚未实现该频道级事务，不得让客户自行升级频道插件。
