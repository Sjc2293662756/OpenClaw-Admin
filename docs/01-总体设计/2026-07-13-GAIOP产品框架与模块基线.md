## 1. 用户主流程

```text
欢迎页
├─ 开始对话 → 登录 → 对话工作台（默认业务空间）
└─ 配置管理 → 登录 → 管理控制台（管理空间）

对话工作台 ⇄ 管理控制台
```

两个工作空间采用整页切换。对话区不嵌入后台卡片，后台左侧也不再保留“在线对话”菜单。

## 2. 模块基线

| 分组 | 模块 | 状态 |
|---|---|---|
| 运行与分析 | 仪表盘、告警通知、会话管理 | 仪表盘/会话保留；告警框架 |
| 智能体管理 | 记忆、任务、模型、频道、Skills、多智能体、智能体工坊 | 保留原功能 |
| 平台管理 | 系统监视器、报告文件、用户、审计 | 基础版本已建立 |
| 系统维护 | 系统设置、系统配置、系统升级 | 部分实现 |

## 3. 设置与配置边界

| 系统设置 | 系统配置 |
|---|---|
| 面向平台使用规则 | 面向部署、集成和安全 |
| 基本行为、会话策略、报告策略、界面偏好 | 主机网络、NAPM 数据源、告警接入、环境敏感配置 |

不增加 IP 白名单和全局通知设置。消息渠道由频道管理负责；Syslog 和告警转发由告警接入配置负责。

## 4. 角色基线

- 基础用户：只读。
- 审计用户：只读并可查看审计。
- 标准用户：对话和常规智能体功能；不能修改安全配置。
- 管理员：全部权限。

菜单可保持可见，但无权限操作必须禁用并由服务端再次拒绝。

## 5. 当前仍保留的未决项

告警、系统升级、多数据源、报告保留、主机网络真实生效、多智能体与工坊分工都在进入对应模块时设计，不改变本框架。
