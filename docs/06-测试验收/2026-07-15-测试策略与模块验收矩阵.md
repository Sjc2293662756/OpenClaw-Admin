## 2. 角色矩阵必测

每个模块至少验证 basic、auditor、standard、admin 四个账号：页面是否可见、按钮是否禁用、直接 REST/RPC 是否拒绝。重点验证审计用户只能查看审计，标准用户不能修改数据源/安全配置，管理员保护最后一个管理员。

## 4. 安全测试

- 直接调用被禁用接口和未授权 RPC。
- 数据源/报告路径穿越、IPv6、超长字段和恶意配置键。
- 响应、日志、审计、浏览器存储中搜索密码、Token、Secret。
- 自签名兼容只作用于单数据源，验证其他 HTTPS 仍严格校验。
- SQLite、报告和桥接文件的服务账号权限。

## 5. 发布门槛

- `npm run build` 通过且无新增类型错误。
- 核心自建接口自动化测试通过。
- 管理员、标准、审计、基础角色回归通过。
- 登录、对话、数据源查询、报告、用户、审计、设置端到端通过。
- 443、SSE、重启、备份恢复和日志脱敏在目标系统通过。
- 文档状态、接口字段和已知限制与交付版本一致。
