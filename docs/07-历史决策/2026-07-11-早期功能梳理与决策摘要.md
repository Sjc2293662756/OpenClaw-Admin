# 早期功能梳理与决策摘要

| 属性 | 内容 |
|---|---|
| 形成日期 | 2026-07-11 |
| 状态 | 历史归档，不作为当前接口依据 |

早期首先确认：保留原开源项目的智能体管理主体，隐藏远程终端、远程桌面和虚拟公司；加入用户、权限、审计、系统配置和升级框架；不重复建设 NAPM 的专业监控展示。

随后确认产品从“后台管理页面换皮”调整为“双工作空间”：对话是默认业务入口，后台是第二空间。文件浏览器收敛为报告文件管理；告警独立成模块；系统设置与系统配置拆分。

该阶段曾讨论 IP 地址管理、访问控制、全局通知、智能体服务地址和更多运维模块，最终结论为：不建设 IP 白名单和全局通知；不让用户配置 GAIOP 连接自身；NAPM 作为数据源单独配置；功能细节在对应模块开发时确认。

当前权威结果见 `01-总体设计` 和 `02-模块设计`。

同目录下的 `images-原项目界面` 保存当时盘点原开源项目功能时的界面截图，只用于追溯和改造前后对照，不代表当前 GAIOP 页面或正式产品范围。
