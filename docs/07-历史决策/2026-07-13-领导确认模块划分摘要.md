# 领导确认模块划分摘要

| 属性 | 内容 |
|---|---|
| 形成日期 | 2026-07-13 |
| 状态 | 历史确认记录 |

确认的控制台模块包括仪表盘、告警通知、会话、记忆、任务、模型、频道、技能、系统监视器、报告文件、多智能体、智能体工坊、用户、审计、系统设置、系统配置和系统升级。

确认的产品边界：

- 登录后默认进入对话工作台，管理控制台为平级第二空间。
- 在线对话不再作为后台左侧菜单。
- 告警点击后创建普通运维分析对话。
- Syslog 位于系统配置的告警接入与转发。
- 系统设置负责使用策略，系统配置负责部署集成与安全。
- 对外统一 443；多个内部服务对用户表现为同一 GAIOP。
- NAPM 当前单运行源、预留多源；公网/内网不增加额外类型。
- Hermes、远程终端、远程桌面、虚拟公司、数据备份隐藏并保留源码。

此摘要只保留决策来源，当前实现状态以 2026-07-15 文档为准。
