## 权限与数据边界

| 边界 | 当前行为 |
|---|---|
| 四角色默认矩阵 | 无个人覆盖时保持既有 basic、standard、auditor、admin 默认权限 |
| 个人覆盖 | 固定目录内支持 `allow`、`deny` 和恢复角色默认；未知 key、非法 effect、重复项和锁定项拒绝 |
| 账户治理 | `users` 仅 auditor/admin；`userAdministration` 仅 admin；旧数据库中同名个人覆盖也不能越权 |
| 初始管理员 | 19 项目录全部固定允许；普通管理员不能读取或修改目标用户权限配置 |
| 告警 | `alerts.records` 同时控制列表、时间接口和当前页导出；`alerts.notifications` 控制补偿、偏好、通知和弹窗 SSE |
| 报告 | 默认按可信 `source_user_id` 仅本人；其他或未知归属统一 404；仅 `reports + data.allUsers` 才扩大为全量只读 |
| 会话 | `sessions + data.allUsers` 扩大只读范围；发送、停止、重置、修改和删除继续按角色与可信归属裁决 |
| 仪表盘 | `dashboard + data.allUsers` 才使用全量会话聚合，否则为本人范围；始终只读 |
| 高风险模块 | 个人 allow 只打开登记的安全读取；原有管理员、初始管理员、只读角色和动作级门禁继续生效 |
| 在线生效 | 登录和认证检查使用服务端有效权限投影；权限版本变化通过定向 SSE 触发目标用户刷新和失权页面退出 |
