## 1. 权限行为

- 普通用户和标准用户可以查看并删除自己的会话，包括单条删除和批量删除。
- 普通用户、标准用户和审计用户的会话列表由 Admin BFF 按当前登录用户的稳定 ID 过滤，只返回 `workspace_sessions.owner_user_id` 属于当前用户的有效 WebChat 会话。
- 审计用户保持只读，不能删除会话。
- 管理员不应用会话归属过滤，可以查看全部 Gateway 会话，包括所有 GAIOP WebChat 用户和外部频道会话。
- 管理员可以删除任意可见会话。
- 外部频道身份当前没有映射为 GAIOP 登录账户，因此不会作为普通用户的“本人会话”返回；管理员仍可统一查看。
- 普通、标准和管理员页面显示本人授权范围内的单条/批量删除；审计用户不显示选择列和删除入口。
- 前端删除处理函数保留角色守卫；BFF 在调用 Gateway 前先校验角色，再校验会话归属，不能通过直接 REST/RPC 删除其他用户会话。

本次只修改 GAIOP Admin 前端和 BFF 权限，不修改 OpenClaw、Gateway 协议、GAIOP 后端或生产会话数据。
