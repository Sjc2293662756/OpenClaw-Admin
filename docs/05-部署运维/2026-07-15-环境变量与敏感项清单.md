# 环境变量与敏感项清单

| 属性 | 内容 |
|---|---|
| 创建日期 | 2026-07-15 |
| 状态 | 当前代码清单 |

本文只列变量名和作用，不记录真实值。部分变量沿用底层兼容名称，属于内部实现，不应展示在产品页面。

## 1. 管理服务

| 变量 | 敏感 | 用途 |
|---|---:|---|
| `PORT` | 否 | 管理服务监听端口 |
| `DEV_PORT` | 否 | Vite 开发端口 |
| `DEV_FRONTEND_URL` | 否 | 开发提示地址 |
| `AUTH_USERNAME` | 中 | 首次初始化/兼容管理员用户名 |
| `AUTH_PASSWORD` | 是 | 首次初始化/兼容管理员密码 |
| `DATA_SOURCE_ENCRYPTION_KEY` | 是 | 数据源密码加密；生产必需 |
| `SENSITIVE_CONFIG_ENCRYPTION_KEY` | 是 | 敏感配置独立加密，优先使用 |
| `GAIOP_ACTIVE_DATA_SOURCE_FILE` | 路径敏感 | Admin 与核心共享的运行数据源桥接文件；生产必需 |
| `GAIOP_DATA_SOURCE_RUNTIME_FILE` | 路径敏感 | 旧管理端兼容别名；新部署不使用 |
| `GAIOP_REPORTS_DIR` | 路径敏感 | 管理服务与 Skill 共享报告目录 |
| `GAIOP_ALERT_RECEIVER_URL` | 内部地址 | Admin BFF 到正式 Syslog 接收器的受控连接；生产应为本机回环或私网地址 |
| `GAIOP_ALERT_RECEIVER_TOKEN` | 是 | BFF 到接收器的可选内部认证值；仅部署侧注入 |
| `LOG_LEVEL` | 否 | 日志级别；生产避免长期 DEBUG |
| `MEDIA_DIR` | 路径敏感 | 遗留媒体定位，正式能力待收口 |

## 2. Gateway 兼容变量

当前管理服务内部仍读取历史兼容变量以连接 GAIOP Gateway，包括 WebSocket 地址、认证 Token/密码、设备身份路径和智能体工作目录。它们是敏感部署变量，不在 Web 页面展示。后续如改为 `GAIOP_*` 名称，应提供双读兼容和迁移期，不能直接中断现有部署。

## 3. NAPM Skills 回退变量

| 变量 | 敏感 | 用途 |
|---|---:|---|
| `NETINSIDE_HOST` | 否/内部 | 无运行时桥接时的 NAPM 地址回退 |
| `NETINSIDE_USERNAME` | 是 | 回退账号 |
| `NETINSIDE_PASSWORD` | 是 | 回退密码 |
| `NETINSIDE_TLS_INSECURE` | 安全敏感 | 回退 TLS 策略；优先由数据源桥接控制 |
| `NETINSIDE_COOKIE` | 是 | 特定数据包流程兼容值，应避免长期使用 |

管理员启用运行数据源后，桥接配置应覆盖这些回退值。请求参数不得绕过权威运行源。

## 4. 前端构建变量

`VITE_APP_TITLE`、`VITE_APP_VERSION` 和 TTS 相关变量在构建或开发时使用。产品标题应设置为 GAIOP；用户可见页面不得因默认值重新出现原项目名称。

## 5. 已隐藏兼容变量

代码仍包含 Hermes 等已隐藏模块的变量。正式 GAIOP 运行不配置这些值，相关接口已停用。待遗留代码安全删除后再从样例中移除。

## 6. 密钥管理

- 密钥不提交 Git、不写文档、不回显页面。
- 加密密钥应使用高熵随机值并由部署系统提供。
- 轮换前必须设计旧密文解密和重新加密，直接替换会导致现有凭据不可读。
- 备份数据库时同步备份密钥，但分开保管并限制访问。
