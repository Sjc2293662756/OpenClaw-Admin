## 1. ISO 组件

最终交付以已验证的 237 系统镜像为基线，镜像内包含 rsyslog、GAIOP Syslog 接收器、服务定义、日志/事件目录权限和健康检查。管理页面不负责下载、安装或升级系统软件，也不维护另一套安装脚本。

## 2. 配置边界

- 部署侧：接收器监听地址、内部认证值、事件目录、服务用户、rsyslog 与防火墙。
- NAPM 侧：Syslog 目标地址、协议/端口和规则发送动作。
- Admin：只保存启用策略并显示运行状态。
- 频道管理：企业微信、Webhook 等通知凭据与路由。

## 3. 237 兼容验证

237 已存在 UDP/514 rsyslog 规则和兼容日志文件。新增用户级接收器服务读取该文件并在本机回环提供健康接口；服务健康、启用/停用跨重启恢复、持久化分页查询和经本地 3004 隧道的 Admin BFF 适配均已验证。没有改动 rsyslog、防火墙、Gateway 或 NAPM 发送端。

镜像恢复后需完成：rsyslog 接收、服务自启、重启恢复、接收器健康、NAPM 新告警、Admin 浏览器列表和失败提示验收。
