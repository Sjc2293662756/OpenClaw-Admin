# 237 日志与容量只读探针设计

## 状态与范围

本文件描述尚未部署、尚未运行的固定用途探针。它不代表 237 已安装 Caddy、Syslog 或 journald 的留存模板，也不授权轮转、压缩、清理、重启、reload、启用 timer 或修改任何配置。

探针只覆盖固定标签：两个 Caddy 候选根、原始 Syslog、journal 持久化目录、Gateway 应用日志、Admin 状态、正式报告与恢复区、数据包、Upgrade 状态与回滚备份。调用方不能传入命令或路径。

## 安全输出契约

输出只包含以下脱敏汇总：

- 固定标签、存在/权限/符号链接等稳定状态；
- 哈希化文件系统标识、容量、文件总数、字节数、gzip/已轮转数、最早和最新 Unix 时间；
- 固定 service/timer 状态与模板标记枚举；
- Caddy、rsyslog、journald 的 journal 条数、错误条数和最新时间摘要。

输出绝不包含真实路径、文件名、日志正文、journal 原文、环境变量值、Caddyfile 或 rsyslog 配置正文、凭据或任意远端命令输出。目录扫描只汇总元数据，不打印匹配项。

## 已知边界

- `/var/log/gaiop/caddy` 与旧水位资料中的 Caddy 候选根同时以标签呈现，用于确认路径盲点；探针不声称任一根已经是活动日志路径。
- Caddy、Syslog、journald ISO 模板仍应以 `2026-08-09-GAIOP系统与入口日志留存ISO配置.md` 为权威策略说明。模板文件存在或标记匹配，不等同于已由活动服务加载。
- 237 实际日志轮转、压缩、容量和系统日志策略，在本探针经审核、部署并实际运行前一律为 `unknown`。

## Upgrade 预检修复

`gateway237-upgrade-readonly-preflight.cjs` 不再回传或解码任何 `recentJournal` / Base64 journal 字段。它只返回 `journalSummary`：条数、错误条数和经格式校验的最新时间。该变更保持其他预检状态字段不变。

## 发布与回滚

该探针是本机发起的固定受控检查，不在 237 安装常驻文件。发布前必须完成安全单测、Node 语法检查、PowerShell AST 解析和 Admin 构建。经单独授权后才可运行一次；运行不产生生产写入。

若发现输出边界、固定命令白名单或只读性不符合预期，停止使用该探针并回滚本地调用器版本；不得以临时 SSH 命令替代。
