- 不改 GAIOP 后端、报告 Skill、OpenClaw 核心、频道插件、Admin BFF、数据库、报告归档、权限或公网配置。
- 本批次不增加下载按钮；第二阶段将以正式报告归档与 BFF 授权下载为基础实施。

`MEDIA:` 中的绝对路径仍可能存在于 Gateway 原始会话数据中；本批次只消除
GAIOP Admin 工作台的显示和复制暴露，不迁移或改写历史会话。
