1. 候选 Caddyfile 从一开始即可通过语法校验；
2. 最初回环 HTTPS 探针返回 TLS internal error，原因是部分 IP 客户端不发送 SNI，Caddy 无法为无 SNI 握手选择 IP 证书；

4. 随后发现 Caddy `redir ... permanent` 实际返回 301，而早期脚本只接受 308，因此再次自动回滚；
5. 调整验证条件接受 301/308 后，`20260804T090407Z` 正式发布成功。
