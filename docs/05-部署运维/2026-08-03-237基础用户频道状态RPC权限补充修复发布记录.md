## 1. 问题与根因

2026-07-31 的补充发布已将基础用户加入频道页面路由，`GET /api/channels/config` 也能返回不含配置内容的安全状态投影，但页面加载还会同时请求：

- `channels.status` / `channels.list`：频道运行状态；
- `plugins.list` / `plugins.status`：组件安装与可用状态。

服务端 RPC 权限矩阵仍只允许标准和审计用户读取这些方法。基础用户的 `Promise.all` 因 RPC 403 整体失败，因此同时显示“基础用户无权读取此管理模块”和“读取频道状态失败”。上一批次的路由与 REST 测试未覆盖该组合请求，导致漏项未被发现。

## 2. 修复范围

- 基础、标准、审计用户均允许读取频道和插件状态 RPC；返回值继续经过 Admin BFF 安全字段投影。
- 基础用户仍不能读取 Skills、模型、智能体、任务或其他管理模块。
- 频道配置、凭据、启停、保存、应用和扫码开通仍只允许管理员操作。
- 本次不修改频道页面样式、Gateway、OpenClaw 核心、频道插件或生产数据。
