## 2. 故障原因

Admin 前端路由使用按页面拆分的哈希文件。旧标签页在发布前已经加载旧入口脚本，发布切换后首次进入未加载过的页面时，仍会请求旧哈希文件。

此前发布会整体替换 `dist`，旧文件随之消失；同时静态资源未命中后继续进入 SPA 回退，服务端返回 `index.html`。浏览器收到 `200 text/html` 后无法将其作为 JavaScript 模块执行，路由组件加载失败，页面主区域表现为白屏。

该机制确实会影响发布前旧标签页首次进入哈希已变化的懒加载路由，但它是本次排查中发现并修复的次生风险，不是当次“点击添加用户立即白屏”的真实根因。

## 3. 修复范围

### 3.1 服务端

- 新增缺失静态资源中间件；
- `/assets` 和 `/assets/*` 未命中时直接返回非缓存404；
- `/index.html` 使用非缓存响应；
- 普通前端路由仍按原规则回退到 SPA 入口。

### 3.2 前端

- Vue Router 注册分包加载错误处理；
- 仅识别浏览器动态模块加载错误；
- 同一地址最多自动刷新一次；
- 正常导航后清理刷新标记；
- 普通路由守卫错误不触发刷新。

### 3.3 发布兼容

受控 Admin 发布脚本在切换前：

1. 记录本批次实际生成的静态资源清单；
2. 将当前在线版本清单中的哈希资源复制到新版本；
3. 新版本同名文件优先；
4. 下一次发布只保留当前版本的一代资源，不无限累积历史文件。

首次使用新清单机制时，兼容复制当前在线版本全部静态资源。
