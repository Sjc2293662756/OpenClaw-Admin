## 结论

19:53:37（Asia/Hong_Kong）的生产请求“生成最近三天的巡检报告”被精确定位到唯一 WebChat 会话和唯一插件 turn。该 turn 出现

## 最小修复

1. 在 workspace 和 extension 两个生产候选副本中，把精确 WebChat `sessionKey` 设为自动派发的优先拒绝条件；随后仍仅允许 `channelId === wecom`。真实企业微信路径未扩大，其他频道仍不归自动派发所有。
2. 未修改 Skill、OpenClaw 核心、报告生成服务、Admin 前端/BFF、角色、模块权限、报告下载、预览、删除或恢复区。
3. 对已损坏报告只使用同一审计 turn 的精确会话、报告 ID，以及 Gateway 原始 transcript 中唯一持久 assistant 消息 ID 补来源。未按文件名、报告时间、最近消息或会话末尾猜测，未修改 Gateway transcript 或报告正文。
4. 常规提醒已写入报告链路注意事项和 `AGENTS.md` 既有普通入口，不提升为全仓库最高级门禁。
