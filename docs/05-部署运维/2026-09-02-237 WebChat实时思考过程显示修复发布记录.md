# 2026-09-02 237 WebChat 实时思考过程显示修复发布记录

## 问题

账户级“显示思考过程”已有保存能力，但页面仅在输入区显示短暂的共享智能体状态，未限定当前会话，且安全步骤默认折叠。用户在后续会话中切换选项时难以观察到稳定、可归因的实时差异。

## 修复

- 保留用户可见名称“显示思考过程”及既有二选一值，不改账户级存储、接口、默认值或任何角色权限。
- 仅在当前选中会话处于发送、等待、思考、工具执行、回复或停止阶段时显示过程；完成、空闲、错误后的历史过程不回填。
- 开启时实时状态与安全步骤自动展开；关闭时不渲染实时过程区域。
- 其他会话的共享 `agent:main` 状态不会投影到当前会话；报告卡片、正式回复、流式 transport、停止操作与历史投影不受影响。
- Office 对话面板同步使用其选中会话 key，避免错误依赖全局 chat store 的当前 key。

该功能展示的是安全的执行状态和工具步骤，不显示模型隐藏推理文本，也不改写 Gateway 历史。
