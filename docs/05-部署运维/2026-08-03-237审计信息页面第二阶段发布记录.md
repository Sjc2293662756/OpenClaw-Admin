## 1. 范围与边界

本批次改造 GAIOP-Admin 审计信息页面，并补充审计查询返回的安全投影。未进行 SQLite 迁移，未修改第一阶段审计写入、权限拒绝、401/410 限频、遗留入口410或四角色权限规则。

- 页面默认查询今日，复用统一时间范围组件提供今日、昨日、最近7日、最近30日和自定义。
- 关键词、用户名、角色、分类、结果、来源、错误码、时间范围、分页、总数和五项汇总均由服务端 `GET /api/audit-logs` 完成；默认每页20条，可切换20、50、100条。
- 页面提供只读详情抽屉和请求编号复制；空字段显示“历史未记录”，来源地址不宣称一定是真实客户端 IP。
- BFF 仅新增 `actorUserId` 安全投影与 `summary.unclassified` 历史未结构化数量，保证 `total = success + failed + denied + unclassified`。
- 未修改 GAIOP 后端、OpenClaw、Gateway、Skills、频道插件、升级模块、Caddy、防火墙、DNS、证书或公网配置。

## 2. 安全与交互验证

- 快速连续查询使用请求代次和 `AbortController`，旧响应不会覆盖新条件；加载时保留现有列表，接口失败也保留上次结果并明确提示。
- 审计读取不写入“查看审计”事件；基础和标准用户仍由前后端权限矩阵拒绝，审计用户和管理员可查看。
- 列表和抽屉只展示安全投影，不展示原始 Body、查询参数、Token、密码、Cookie、密钥、RPC 参数、聊天内容、报告正文或敏感配置。
- Node 隔离 Express/内存 SQLite 验证了基础、标准用户直接查询403，审计与管理员查询成功且不产生新的审计读取噪声；第一阶段 REST/RPC、隐藏404、401/410限频、账号安全和归属回归保持通过。
