## 3. 根因

Gateway 历史归一化同时提供用户消息的 `content` 和 `rawContent` 文本。两者内容相同，但 `messageText()` 原先直接拼接，得到重复的用户提示，导致与 `source_message_preview` 的精确回退匹配失败。由于持久 Gateway ID 与登记的 `web-*` 乐观 ID 不同，精确 ID 匹配也无法命中，最终报告没有 transcript 目标。
