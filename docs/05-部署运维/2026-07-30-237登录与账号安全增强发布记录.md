# 237 登录与账号安全增强发布记录

## 1. 范围与结论

本次仅修改 GAIOP-Admin 的认证、用户管理、SQLite兼容迁移、前端首次改密引导和受控Admin发布回滚链路。未修改 OpenClaw、频道插件、GAIOP后端、网络、防火墙、证书、Caddy或公网入口。

237已于2026-07-30使用批次 `20260730T090936Z` 完成受控发布。发布后：

- 新建、本人改密和管理员重置统一执行“至少8位，必须同时包含英文字母和数字”的前后端规则；
- 固定共享重置密码和旧认证回退已移除；
- 同一用户名按大小写不敏感连续失败5次后锁定5分钟，成功登录清空计数；
- 管理员重置改为输入临时密码，撤销目标用户Token并设置首次改密；
- 临时密码登录只允许认证检查、退出和本人改密，其他REST、工作台和Gateway RPC由服务端统一拒绝；
- 改密成功清除首次改密标记、撤销旧Token并要求重新登录；
- 现有最早创建且仍激活的管理员被唯一标记为初始管理员；
- 普通管理员只能管理基础、审计和标准用户；初始管理员可管理其他管理员；
- 初始管理员不能删除、停用、降级或被他人重置，标记不能通过页面或普通接口转移。

- `is_initial_admin INTEGER NOT NULL DEFAULT 0`；
- `must_change_password INTEGER NOT NULL DEFAULT 0`；
