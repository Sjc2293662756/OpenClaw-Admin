## 2. 插件安装

- 命令：`openclaw plugins install "@tencent-weixin/openclaw-weixin@2.4.4"`；
- 落位：`~/.openclaw/npm/node_modules/@tencent-weixin/openclaw-weixin`，自动生成 `node_modules/openclaw → 全局核心` 软链；
- 启用：`plugins.entries.openclaw-weixin.enabled=true`，`plugins.allow` 追加；
- catalog 软链：`~/.openclaw/extensions/openclaw-weixin → npm 插件目录`（2026.5.4 缺陷绕法）；
- 安装后核对企微/飞书/钉钉软链完好、Gateway 正常、频道目录可识别。

## 3. 扫码登录流程

1. 管理员填写账户名称/备注，BFF 创建会话并调适配器 `/qr/start`；
2. 适配器启动 worker，worker 调用插件 `startWeixinLoginWithQr` 获取二维码 URL；
3. BFF 用 `qrcode` 生成二维码图返回前端（不进日志/审计）；
4. 前端轮询，BFF 长轮询适配器 `/qr/wait`；状态：等待扫码 → 已扫码 →（如需）验证码 → 成功/过期/失败/取消；
5. 成功后 worker 用插件函数保存凭据（`saveWeixinAccount`/`registerWeixinAccountId`/`clearStaleAccountsForUserId`/`triggerWeixinChannelReload`）并写入账号配置 `channels.openclaw-weixin.accounts.<id>.enabled=true`；
6. BFF 把管理信息写入 SQLite 并审计。

验证码：worker 内插件 `waitForWeixinLogin` 输出提示，适配器识别后返回 `verification_required`，管理员提交后适配器把验证码写入 worker stdin（插件原生读取）。

## 6. 实施中修复的问题

1. **适配器 Token 头未发送**：BFF 最初未携带 `X-GAIOP-Weixin-Token`，导致 `PERSONAL_WECHAT_ADAPTER_UNAUTHORIZED`；已由 BFF 从环境变量读取并随请求发送。
2. **Gateway 不启动微信频道**：OpenClaw 2026.5.4 只把“有账号级配置”的频道视为已配置；扫码后 worker 现在自动写入 `channels.openclaw-weixin.accounts.<id>.enabled=true`，Gateway 重启后频道与账号正常启动。
3. **binding 不生效**：缺省 accountId 被归一化为“default 账号”，真实账号不命中；显式 `match.accountId:"*"` 后会话键变为 per-account-channel-peer。
4. **启用/停用后返回“异常”、刷新后正常**：启停接口原先只返回薄快照（无 configured/running），合并被误判为“未配置”；现改为启停后重新拉全量快照（适配器 + Gateway）返回。
5. **账号离线显示**：两处修复——
   - BFF 原先调用顶层 `status` RPC，其账号条目不带 `running` 字段，合并时被错误置为 false 导致“离线”；现改调 `channels.status` RPC（与 CLI 同源），并只在字段为布尔时采用；
   - Gateway 状态合并失败时（重启/重连窗口）显示“状态未知”而非“离线”，前端每 20 秒自动刷新自愈。
6. **删除/启停过慢**：原删除走两次 `openclaw config` CLI（各约 5 秒，合计约 10 秒），启停各约 5 秒（CLI/SDK 配置写入含完整 schema 校验）。现改为对 `openclaw.json` 的 `channels.openclaw-weixin` 段做**直接原子 JSON 编辑（保留 .bak）**，删除/启停耗时降至约 3 毫秒（适配器冷启动后首次删除约 2.6 秒，为一次性插件模块加载）；前端删除改为先行移除、失败回滚。另修复适配器部署脚本：服务已在运行时 `enable --now` 不会重启进程，改为显式 `restart`。
7. **二维码生成慢 / 扫码成功慢**：原每次扫码会话冷启动 worker（约 2.5-3 秒加载插件模块），且扫码成功后 worker 还执行一次 `openclaw config set`（约 5 秒）。现改为：**常驻 worker 池**（适配器启动预热，fd0 验证码通道 / fd3 命令通道），二维码生成约 0.2 秒（冷启动后首次约 2.2 秒）；扫码成功路径的账号配置写入改为直接原子 JSON 编辑（毫秒级）。前端文案同步调整（账户名称占位改为“输入账户名称”，去掉“二维码和登录凭据不会写入普通日志”声明句）。

### 已知：启停/删除会触发微信频道热重启

每次启停/删除会写 `channelConfigUpdatedAt`，OpenClaw 据此对 `channels.openclaw-weixin` 执行热重启（数秒，期间该频道账号短暂重启）。这是 OpenClaw 的 reload 机制，非管理员操作不触发；如需避免，需在核心层调整 reload 策略（超出本模块范围）。
