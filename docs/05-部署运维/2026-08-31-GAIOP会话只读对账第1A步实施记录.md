## 3. 存储边界

- OpenClaw 继续负责会话索引、正文、运行态和活动运行，是会话正文的权威来源。
- Admin `wizard.db` 只读取用户归属、WebChat 登记、报告来源、附件登记、频道交付登记、留存元数据和任务状态聚合。
- 前端不参与本步，也不保存服务器业务正文。
- BFF 入口不扫描 OpenClaw 目录，不读取会话正文、报告正文或附件内容，不管理或删除 OpenClaw 文件。
- Admin `tasks` 表没有会话键。本步只聚合活动状态行数，不读取 `conversation_history` 或 `execution_history`，因此 Admin 活动任务到会话的关系固定标为 `unknown`。
- `report_deliveries.report_id` 只能经 `report_files.source_session_id` 间接关联会话；频道发送副本没有逐文件登记关系，逐文件对应固定标为 `unknown`。

## 4. 只读实现

入口 `npm run reconcile:sessions:dry-run` 固定执行 `server/session-reconciliation.js`，不接受数据库路径、OpenClaw 可执行文件或任意命令参数。

SQLite 门禁：

- 数据库路径固定为 `/var/lib/gaiop/admin/wizard.db`。
- 使用 `readonly: true`、`fileMustExist: true` 打开连接。
- 设置 `PRAGMA query_only=ON` 和内存临时存储。
- 运行前后比较 `PRAGMA data_version`，并要求 `SELECT total_changes()` 始终为 `0`。
- SQL 仅包含 `SELECT` 和 `PRAGMA`，不导入可写的 `server/database.js`。

OpenClaw 门禁：

- 可执行文件固定为 `/home/netinside/.npm-global/bin/openclaw`。
- 完整索引固定调用 `sessions --agent main --json --limit all`。
- 活动运行固定调用 Gateway `sessions.list`，明确关闭派生标题和消息预览。
- 缺正文检查只调用 `sessions cleanup --agent main --dry-run --fix-missing`。
- 不存在 `--enforce`、`sessions.delete`、`sessions.patch`、`sessions.reset` 或历史/正文预览调用。
- 索引、活动运行和缺正文预演均执行两次；任一指纹变化即返回 `DATA_DRIFT`。

输出门禁：

- 输出只包含数量、分类、原因码、时间、引用计数和固定命名空间 SHA-256 摘要。
- 不输出原始会话键、用户 ID、报告 ID、附件名、真实路径、凭据或子进程原始错误。
- 接口、schema、解析或数据漂移失败时只返回 `unknown`，不附带历史统计。
