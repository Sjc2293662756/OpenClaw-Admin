## 4. 只读实现

入口 `npm run reconcile:sessions:dry-run` 固定执行 `server/session-reconciliation.js`，不接受数据库路径、OpenClaw 可执行文件或任意命令参数。

SQLite 门禁：

- 数据库路径固定为 `/var/lib/gaiop/admin/wizard.db`。
- 使用 `readonly: true`、`fileMustExist: true` 打开连接。
- 设置 `PRAGMA query_only=ON` 和内存临时存储。
- 运行前后读取 `PRAGMA data_version`，并要求 `SELECT total_changes()` 始终为 `0`。
- 对 `workspace_sessions`（含用户状态关联）、报告来源、附件登记、交付登记、留存登记和任务状态聚合分别做前后两次只读快照，以固定字段 SHA-256 指纹判断相关 BFF 元数据是否漂移。
- 相关 BFF 元数据指纹变化返回 `DATA_DRIFT`。仅 `data_version` 或数据库主文件/WAL/SHM 组合摘要变化、而相关指纹稳定时，只记录 SQLite 外部活动观察，不把它归因于本工具写入，也不单独判整次失败。
- SQL 仅包含 `SELECT` 和 `PRAGMA`，不导入可写的 `server/database.js`。

OpenClaw 门禁：

- 可执行文件固定为 `/home/netinside/.npm-global/bin/openclaw`。
- 完整索引固定调用 `sessions --agent main --json --limit all`。
- 活动运行固定调用 Gateway `sessions.list`，参数固定为 `{"limit":100000}`，不请求消息预览或正文。
- `sessions.list` 的 CLI 超时固定为 `60000` 毫秒，Node `execFile` 超时固定为 `75000` 毫秒；237 transient 外层总超时固定为 `360` 秒，均不接受调用方输入。
- 每轮三个 OpenClaw 探针严格串行执行，顺序为 `index → missing → runtime`；完整对账仍执行两轮并比较指纹。
- transient unit 使用 `id -u netinside` 动态构造 `XDG_RUNTIME_DIR=/run/user/<uid>`，不硬编码 UID。本次证据表明不需要设置 `DBUS_SESSION_BUS_ADDRESS`，实现未设置该变量。
- 缺正文检查只调用 `sessions cleanup --agent main --dry-run --fix-missing`。
- 不存在 `--enforce`、`sessions.delete`、`sessions.patch`、`sessions.reset` 或历史/正文预览调用。
- 索引、活动运行和缺正文预演均执行两次；任一指纹变化即返回 `DATA_DRIFT`。
- Gateway 运行目录缺失、超时、不可用、非零退出、JSON 无效和结构无效分别映射为固定脱敏原因码；不输出原始 stderr、命令正文或异常消息。

输出门禁：

- 输出只包含数量、分类、原因码、时间、引用计数和固定命名空间 SHA-256 摘要。
- 不输出原始会话键、用户 ID、报告 ID、附件名、真实路径、凭据或子进程原始错误。
- 接口、schema、解析或数据漂移失败时只返回 `unknown`，不附带历史统计。
