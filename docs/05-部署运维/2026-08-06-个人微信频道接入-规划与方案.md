# 2026-08-06 个人微信频道接入：规划与方案

> 本文件为规划/方案文档。实施与部署见《2026-08-06-个人微信频道接入-实施与部署记录.md》，报告管理器适配见《2026-08-06-个人微信报告接入GAIOP报告管理器-适配记录.md》，备份回滚见《2026-08-06-个人微信频道-备份回滚与运维记录.md》。

## 1. 目标

在 GAIOP Admin“频道管理”页新增独立“个人微信”模块：

- 扫码添加个人微信账号（账户名称/备注 → 二维码 → 扫码 → 成功进列表），支持第 2、3 个账号；
- 账号级隔离，多个微信号互不串上下文；
- 支持启用、停用、删除单个账号；删除只删该账号授权/管理信息，不卸载插件；
- 首次安装插件与日常添加账号严格分离，账号增删不得触发 npm install / 插件升级 / 依赖重建；
- 微信 Token、登录凭据由 OpenClaw 个人微信插件原生保存，GAIOP 不复制、不明文保存、不返回；
- 不破坏现有企业微信、飞书、钉钉频道。

## 2. 整体架构

```
浏览器(公网 HTTPS 443 → Caddy → 127.0.0.1:3000)
  → GAIOP Admin BFF (gaiop 用户, 127.0.0.1:3000)
  → 个人微信适配器 (netinside 用户, 127.0.0.1:19091, systemd 用户服务)
  → @tencent-weixin/openclaw-weixin@2.4.4 插件 dist 函数
  → 腾讯 iLink Bot API (https://ilinkai.weixin.qq.com)
```

职责边界：

- Admin BFF：扫码会话编排、GAIOP 管理信息（SQLite）、审计、与 Gateway 状态合并；
- 适配器：调用插件自身导出的扫码/凭据/账号函数，凭据只写入插件存储；回环 HTTP + 随机 Token 头鉴权；
- 插件：保存每个账号的 Token/baseUrl/userId，原生管理登录状态。

## 3. 安全边界

- GAIOP 只保存：账户名称、备注、accountId、userId、enabled、创建人、时间戳；
- 不保存/不返回：微信 Token、二维码授权数据、登录凭据；
- 二维码/Token 不进普通日志与审计日志；
- 适配器仅监听 127.0.0.1:19091，BFF 用 `PERSONAL_WECHAT_ADAPTER_TOKEN` 请求头调用；
- 频道管理仍为 admin-only，现有权限体系不被破坏。

## 4. 插件版本与依赖处理原则

- 237 现状：OpenClaw 2026.5.4、Node v22.14.0、共享依赖树 `~/.openclaw/npm/node_modules`；
- 固定安装 `@tencent-weixin/openclaw-weixin@2.4.4`：2.4.6 的 `minHostVersion>=2026.5.12` 会被 237 拒绝，2.4.4 要求 `>=2026.3.22` 兼容；
- 安装走 `openclaw plugins install`（框架原生），不触碰其他插件；安装后核对企微/飞书/钉钉软链完好；
- 2026.5.2–<2026.5.12 的 channel catalog 缺陷按官方做法以 `~/.openclaw/extensions/openclaw-weixin` 软链绕开；
- 账号添加/启停/删除只调用插件扫码/账号函数与 `openclaw config`，不执行安装/更新/卸载/npm 操作。

## 5. 会话隔离方案

- `openclaw.json` 新增 binding（**`match.accountId` 必须为 `"*"`**，缺省会被当作“只匹配 default 账号”而失效）：
  ```json
  {
    "type": "route",
    "agentId": "main",
    "match": { "channel": "openclaw-weixin", "accountId": "*" },
    "session": { "dmScope": "per-account-channel-peer" }
  }
  ```
- 会话键：`agent:main:openclaw-weixin:<accountId>:direct:<peer>`，不同微信账号/联系人上下文隔离；
- 全局 `session.dmScope` 保持 `per-channel-peer`，企微/飞书/钉钉会话键格式不变。

## 6. 验收标准对照

- 添加个人微信 → 填名称/备注 → 二维码 → 扫码 → 进列表 → 可继续添加第 2、3 个 → 每账号独立 → 可启用/停用/删除；
- 企业微信/飞书/钉钉正常，Gateway 正常，Admin 正常；
- 237 已部署、Git 已提交推送、文档已记录、有实施前完整回滚备份。
