## 1. 集成内容

Admin 基线已包含第一批来源信封/升级中转清理和系统与入口日志 ISO 配置；本批在该基线上精确摘取并组合：

- 正式报告 365 天、7 天恢复区、长期保留和成组恢复；
- Admin `wizard.db` 日 30、周 12、月 12 的一致性备份与临时恢复验证；
- Gateway 真实活动会话 180 天、7 天待删除、取消和长期保留；
- 75%/80%/90% 磁盘水位只读监测与受限告警。

Upgrade 基线已包含升级包、staging 和组件回滚备份清理；本批精确摘取 Upgrade SQLite 日/周/月备份与临时恢复验证。组件回滚根 `/var/backups/gaiop/upgrade` 与 SQLite 备份根 `/var/lib/gaiop/upgrade/sqlite-backups` 保持分离，最近 5 个可用组件回滚版本保护规则未改变。

后端实时 `origin/main` 仍是 phase1 的共同祖先，因此没有新建或重写分支，只验证现有集成分支包含原始数据包 24 小时留存、应用文件日志轮转/到期清理、解析告警 SQLite 与 365 天留存。
