# 入口与登录模块设计

| 属性 | 内容 |
|---|---|

| 最后更新 | 2026-08-04 |
| 状态 | 已实现 |
| 代码依据 | `src/views/EntrancePage.vue`、`src/views/Login.vue`、`src/stores/auth.ts`、`server/routes/auth.js` |

## 1. 目标与边界

提供统一品牌入口和用户名密码认证。模块不承担注册、密码找回、手机号、验证码、二维码和第三方单点登录。

## 2. 页面与流程

| 页面 | 路由 | 功能 |
|---|---|---|
| 欢迎页 | `/welcome` | 品牌展示、开始对话、配置管理 |
| 登录页 | `/login` | 用户名、密码、登录反馈 |

```text
开始对话 → /login?redirect=/workspace → /workspace
配置管理（审计、标准、管理员）→ /login?redirect=/ → /
配置管理（基础用户）→ /login?redirect=/ → /workspace + 居中无管理权限提示
退出登录 → /welcome?redirect=/
```

已登录用户再次访问登录页时，路由守卫应按合法 `redirect` 返回目标；基础用户从“配置管理”进入时改回对话工作台并显示“当前账户没有管理权限”提示，不进入管理控制台或整页无访问权限页；不得接受外部 URL 作为跳转地址。

## 3. 权限与数据

- 所有人可访问欢迎页、登录页和认证配置接口。
- 登录只接受状态为 `active` 的数据库用户；兼容无数据库用户时的初始环境账户。
- 登录成功创建内存 Token 会话，返回用户 ID、用户名和角色；密码仅用于本次校验。
- 退出后删除当前 Token 并记录审计。

## 4. 异常与安全

- 用户名或密码为空：`400 LOGIN_INPUT_REQUIRED`。
- 账号不存在、停用或密码错误：统一 `401 INVALID_CREDENTIALS`，避免泄露账号状态。
- Token 失效：前端清理登录态并跳转登录/欢迎流程。
- 生产环境必须替换初始密码；真实密码不得写入文档、截图和日志。

## 5. 验收标准

- 管理权限用户从两个入口分别进入正确工作空间；基础用户从“配置管理”登录后回到对话工作台并看到无管理权限提示。
- 注册、找回、二维码和手机号入口不存在。
- 错误密码不创建会话；停用用户不能登录。
- 退出后原 Token 不可继续访问受保护接口，页面回到欢迎页。

## 6. 已知限制

Token 当前保存在管理服务内存，服务重启后全部失效；尚无失败次数锁定、首次登录强制改密和持久化会话。
