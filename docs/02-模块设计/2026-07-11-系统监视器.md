## 1. 目标与数据含义

展示 GAIOP 管理服务所在主机的 CPU、内存、磁盘、网络、运行时长和基础系统信息。当前本地运行时显示开发电脑资源；部署到麒麟后才显示麒麟服务器资源。它不是 NAPM 监控数据，也不代表远端 NAPM 主机资源。

## 2. 当前功能

- 每 5 秒自动刷新和手动刷新。
- CPU 使用率/核心数、内存使用量、磁盘使用量。
- 网络收发字节和连接数。
- 运行时长、平台、主机名和在线实例数量。
- 依据 CPU、内存、磁盘阈值显示绿色、黄色、红色状态。

## 3. 权限和边界

所有登录用户可只读查看；不通过该页面执行系统命令或修改主机。数据仅用于管理诊断，不替代 NAPM 的网络、应用和业务性能分析。

## 4. 异常与验收

- 指标接口失败时保留上次刷新时间并标识数据失效，不显示伪造的 0。
- Windows、麒麟和 Ubuntu 的磁盘/网络统计差异应有兼容处理。
- 页面明确显示所监测主机名，避免被理解成 NAPM 服务器。
- 认证过期应引导重新登录。

## 5. 后续

补充前端、管理服务、Gateway、运行数据源等组件级健康状态，并建立不同操作系统的指标测试。
