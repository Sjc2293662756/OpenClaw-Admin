## 1. 目标

管理控制台是 GAIOP 的第二工作空间，承载运行概览、智能体管理、平台管理和系统维护。仪表盘只展示 GAIOP 自身的会话、Token、模型、Skills、任务和 Usage，不复制 NAPM 专业监控页面。

## 2. 页面能力

- 日期范围：最近1小时、今日、昨日、最近7日、最近30日、本月、自定义。
- 指标：总会话、启用任务、模型、Skills、Token、消息量、工具调用、错误率、平均 Token、缓存读取、活跃天数。
- 图表：Token/费用趋势、Usage 结构和排行。
- 快捷入口：会话、任务、模型、对话工作台。
- 顶部展示 GAIOP 服务连接状态；左侧菜单承载正式模块。

## 3. 数据与权限

数据主要来自 Gateway Usage、会话、任务、模型和 Skills RPC。所有角色可查看基础概览；涉及费用、全局用量或跨用户统计的范围后续应按产品授权细化。

## 4. 异常与边界

- 无 Usage 数据时显示空状态，不伪造趋势。
- Gateway 不可用时区分“管理服务在线”和“智能体服务离线”。
- 系统监视器显示当前运行主机资源，仪表盘不重复展示操作系统详情。
- 页面不得显示底层框架版本、升级提示或外部产品名称。

## 5. 验收标准

- 登录“配置管理”后进入管理控制台。
- 切换日期能触发正确查询；空数据和错误状态清晰。
- 左侧正式菜单与总体架构一致，隐藏模块不可达。
- 顶部可完整切换到对话工作台。

## 6. 已知限制

Token/费用的用户范围和口径尚未最终定义；仪表盘是否增加 NAPM 数据源连通状态待后续产品确认。
