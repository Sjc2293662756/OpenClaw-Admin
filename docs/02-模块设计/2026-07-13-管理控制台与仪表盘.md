## 1. 目标

管理控制台是 GAIOP 的第二工作空间，承载运行概览、智能体管理、平台管理和系统维护。仪表盘只展示 GAIOP 自身的会话、Token、模型、Skills、任务和 Usage，不复制 NAPM 专业监控页面。

## 2. 页面能力

- 日期范围：最近1小时、今日、昨日、最近7日、最近30日、本月、自定义。
- 指标：总会话、启用任务、模型、Skills、Token、消息量、工具调用、错误率、平均 Token、缓存读取、活跃天数。
- 图表：Token/费用趋势、Usage 结构和排行。
- 快捷入口：会话、任务、模型、对话工作台。
- 顶部展示 GAIOP 服务连接状态；左侧菜单承载正式模块。

## 3. 数据与权限

数据主要来自 Gateway Usage、会话、任务、模型和 Skills RPC。管理员和审计用户按各自已授权的全局查看范围读取汇总；基础和标准用户的消息数、Token、费用趋势、模型、供应商和工具指标必须先按 `workspace_sessions.owner_user_id` 筛选本人有效 WebChat 会话，再从这些会话明细重新聚合。浏览器不能收到全局聚合后自行清零，也不能用全局汇总减去其他用户数据。

本人聚合随 Gateway 返回的本人会话使用明细变化：新增消息、Token 或工具调用后，下一次强制刷新立即重算；普通刷新使用按用户、归属集合和时间范围隔离的短缓存。仪表盘 BFF 投影只保留展示所需字段，不把会话标题、单会话日明细或跨用户会话信息返回浏览器。

## 4. 异常与边界

- 无 Usage 数据时显示空状态，不伪造趋势。
- Gateway 不可用时区分“管理服务在线”和“智能体服务离线”。
- 系统监视器显示当前运行主机资源，仪表盘不重复展示操作系统详情。
- 页面不得显示底层框架版本、升级提示或外部产品名称。

## 5. 验收标准

- 登录“配置管理”后进入管理控制台。
- 切换日期能触发正确查询；空数据和错误状态清晰。
- 左侧正式菜单与总体架构一致，隐藏模块不可达。
- 顶部可完整切换到对话工作台。

## 6. 已知限制

仪表盘是否增加 NAPM 数据源连通状态待后续产品确认。基础/标准用户的本人 Usage 口径已固定；外部频道身份尚未映射为 GAIOP 登录用户，因此不会计入这两类用户的“本人”指标。

固定截取最后14天、查询竞争、自定义日期提交、长查询反馈、趋势轴标签和年月弹层问题已于2026-07-28至29完成修复和237发布。当前共用 `TimeRangePicker` 与统一时间纯函数；长范围按日/周/月选择粒度，只有最后一次确认请求可以更新页面。实施细节见[仪表盘时间范围统一与长区间查询修复规划](2026-07-27-仪表盘时间范围统一与长区间查询修复规划.md)，发布证据见[仪表盘时间范围修复](../05-部署运维/2026-07-28-237仪表盘时间范围修复发布记录.md)、[趋势轴与年月选择修复](../05-部署运维/2026-07-29-237仪表盘趋势轴与年月选择修复发布记录.md)和[全局时间范围统一](../05-部署运维/2026-07-29-237全局时间范围组件统一发布记录.md)。
