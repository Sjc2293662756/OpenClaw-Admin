## 1. 定位和权限

系统配置管理部署、集成和安全参数，默认仅管理员修改。普通用户可按模块需要只读查看非敏感状态，但不能获得密码、Token、私钥或底层连接细节。

## 2. 分区状态

| 分区 | 当前能力 | 状态 |
|---|---|---|
| 主机与网络 | 主机名、域名、IP、掩码、网关、DNS、内部地址、时区、NTP、语言保存 | 基础版本已实现 |
| 数据源管理 | NAPM CRUD、加密密码、测试、自签名兼容、唯一运行源和桥接 | 本地运行时闭环已验证 |
| 告警接入与转发 | 占位入口 | 暂缓 |
| 环境与敏感配置 | 不作为正式产品入口 | 数据源凭据归数据源管理，Gateway/部署凭据仅由服务器部署维护 |

## 3. 主机与网络边界

当前保存的是 GAIOP 管理配置，不调用系统命令、不修改网卡、DNS、NTP 或主机名。页面如果继续保留编辑能力，应明确“保存配置记录”；若未来要修改操作系统，必须另建受控系统服务、预检、回滚和权限流程。

## 4. 数据源规则

- 页面用 IP，类型只区分本机/远程；远程同时覆盖内网和公网。
- 数据源可以多条，但当前只有一条 `is_active=1` 的运行数据源。
- 测试验证目标 HTTPS、账号密码和 `applianceInfo` 接口。
- NAPM 自签名证书只对该数据源启用专属兼容模式，不全局关闭 TLS 校验。
- 管理员显式启用后写入受控运行时桥接；无桥接时 Skills 保留原环境变量回退。
- 数据源管理页展示桥接是否已配置、是否已生成及当前运行数据源；不展示桥接文件路径或凭据。
- `GET /api/data-sources` 的 `runtime` 只返回 `ready`、`generated` 和 `mode` 状态，不返回桥接位置、上游地址、账号或密码。
- GAIOP 的插件装载器和 NAPM Client 均在 Skill 调用前读取当前桥接；运行日志只记录调用是否发生及非敏感状态，不记录上游地址、账号、密码或错误响应原文。

### 4.1 本地运行时闭环验证（2026-07-15）

本轮已完成以下可验证链路：

```text
数据源管理页状态
→ Admin BFF runtime 状态
→ SQLite 加密数据源与受控运行时桥接
→ GAIOP NAPM Skill 调用前加载激活源
→ NAPM topValues 实际查询成功
```

- 权限：数据源写入、启用和测试仍由管理员接口校验；非管理员不取得凭据或桥接详情。
- 审计：数据源操作保留管理审计；Skill 运行日志不记录桥接路径、账号、密码、上游地址或错误响应原文。
- 验证：以当前激活源执行一次 `topValues` NAPM Skill 调用，成功返回 25 行；验证输出仅保留成功状态、服务类型与行数。
- 边界：这验证的是本地 Admin 运行时桥接到 GAIOP Skill 的实际 NAPM 消费。麒麟部署、Gateway/Web 会话联调及多数据源绑定策略仍须按部署环境分别验收。

## 5. 部署凭据边界

环境与敏感配置不再作为正式页面或系统配置卡片提供。NAPM 账号、密码和证书兼容选项只在数据源管理中受控维护；Gateway 地址、Token、报告目录和服务器证书由部署人员通过服务端配置维护，浏览器不读取、不编辑也不回显。现有底层加密代码暂时保留，后续遗留治理时再确认删除范围。

## 6. 验收标准

- 非管理员不能修改任一系统配置。
- 数据源密码和敏感值从不明文返回或进入审计。
- 桥接路径、上游地址、账号、密码和错误响应原文不得出现在页面、BFF 响应或 Skill 运行日志中。
- 当前运行数据源不能直接停用/删除；停用源不能测试/启用。
- 主机网络保存不声称已修改操作系统。
- Gateway、部署凭据与证书路径不得出现在页面、BFF 响应或审计中。

## 7. 已知风险与后续

运行时桥接文件含凭据，需部署权限和备份排除；数据源与会话/智能体尚未建立多源绑定；告警配置待 NAPM 样例后设计。
