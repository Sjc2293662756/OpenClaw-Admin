# 基础用户告警与个人报告第一阶段

| 属性 | 内容 |

| 范围 | 告警记录、告警通知/弹窗、个人报告读取 |

## 1. 目标与非目标

基础用户可查看系统级告警记录，接收既有实时告警通知，并查看、预览和下载自己的报告。本期不实现管理员逐用户勾选模块权限，不改变角色定义、GAIOP 后端、OpenClaw 核心或频道插件。

告警记录是系统级只读列表，不按用户归属隔离。报告严格按可信的 `source_user_id` 与当前认证用户稳定 ID 精确匹配；前端筛选不是安全边界。

## 2. 权限矩阵

| 能力 | 基础 | 标准 | 审计 | 管理员 |
|---|---:|---:|---:|---:|
| 告警列表、筛选、分页、详情 | 系统级只读 | 系统级只读 | 系统级只读 | 系统级只读 |
| 告警 SSE、断线补偿、流状态 | 允许 | 允许 | 允许 | 允许 |
| 当前账户通知偏好 | 允许 | 允许 | 允许 | 允许 |
| 告警导出、规则/接收器/系统配置 | 拒绝 | 导出仅当前页；配置拒绝 | 导出仅当前页；配置拒绝 | 依既有管理边界 |
| 报告列表、预览、下载 | 仅本人 | 仅本人 | 全量只读 | 全量 |
| 报告上传、编辑、删除、留存/恢复 | 拒绝 | 拒绝 | 拒绝 | 依既有管理边界 |

基础用户访问他人、未知归属或历史未归属报告时，列表不返回；猜测报告 ID 的预览/下载统一返回 `404 REPORT_NOT_FOUND`，不泄露存在性。

## 3. 实时通知语义

- 浏览器继续只建立既有 Bearer `GET /api/events` 连接；不新增 WebSocket、轮询或另一条 SSE。
- `alert` 与非敏感 `alertStreamState` 对四类角色采用与 `GET /api/alerts` 一致的角色投影；Gateway 会话事件继续按会话归属隔离。
- 现有 SQLite 游标、最近 150 条浏览器内存上限、重连、补偿和去重保持不变。
- 仅本会话实时 `triggered` 事件可产生浮层；`recovered` 和补偿事件只在通知抽屉显示，不播放声音也不产生新浮层。
- 当前账户偏好通过 `/api/alerts/preferences` 读写；请求不接收 `userId`，通知抽屉提供个人设置入口，基础用户不进入系统设置页面。

## 4. 报告预览

PDF 使用经 Bearer 认证的受控预览流；文本、Markdown、JSON、CSV 和日志在浏览器内读取受控文本流。DOCX 等不支持在线预览的格式保持下载入口。所有预览在服务端先执行同一报告归属检查。

## 5. 验收

- 基础用户：告警页面和 `/api/alerts` 成功；`alert`/`alertStreamState` SSE 成功；当前账户通知偏好成功；通知抽屉可标记已读、移除和清空浏览器内项目。
- 基础用户：本人报告列表、下载、受支持预览成功；他人/未归属报告的列表不可见，直接 ID 为 404；上传、删除、留存管理、告警导出与系统管理写操作被拒绝。
- 标准、审计和管理员原有能力保持；非告警敏感 SSE/RPC 不因本期放开。
