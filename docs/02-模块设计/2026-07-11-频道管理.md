## 1. 目标与边界

管理企业微信、飞书、钉钉等消息频道，使用户能够从外部频道发起分析并接收结果。频道管理负责“通过什么频道收发”，不负责 Syslog 接入、告警解析或告警转发规则。QQ 与个人微信当前不纳入页面范围，后续按兼容迁移另行评估。

频道适配组件由 GAIOP ISO 镜像预装并锁定版本。管理页面不提供下载、在线安装、升级插件或执行服务器命令的功能，只负责：

- 检测镜像中频道组件是否就绪；
- 创建和维护频道配置；
- 更新凭据、启用或停用频道；
- 按频道单独保存配置，或保存全部草稿后统一应用配置，并展示 Gateway 运行状态。

组件缺失属于镜像或部署异常，页面只提示检查 ISO 内容和服务状态，不提供修复按钮。

## 2. 当前本地功能

- 三类频道配置卡片：飞书、钉钉、企业微信；QQ 与个人微信已从当前页面隐藏。
- 读取频道组件、配置和启用状态；远程安装入口及 `plugins.install` 调用已移除。
- 未配置频道可创建默认停用的配置草稿，凭据补齐前不会自动启用。
- 已按 237 只读核验的适配器结构对齐：飞书 `channels.feishu` 的 `appId/appSecret`，钉钉 `channels.dingtalk-connector` 的 `clientId/clientSecret`，企业微信 Bot 模式 `channels.wecom` 的 `botId/secret`。
- 飞书“扫码开通飞书”只在尚未配置飞书应用时展示：管理员在页面生成一次性二维码，在飞书确认后由官方设备授权流程创建专属 GAIOP 应用并返回应用凭据；BFF 只在内存中短暂处理凭据并直接写入 Gateway。二维码默认十分钟失效，Admin SQLite、浏览器响应、审计和日志均不保存明文凭据。已有飞书应用必须保留既有机器人并使用手工 App ID/Secret 配置；当前不提供扫码替换。
- 飞书、钉钉和企业微信私聊访问固定为 `open`，成员范围分别由各平台应用后台的可用、授权或可见范围统一管理；GAIOP 不重复维护白名单、配对或拒绝策略。历史策略仅在管理员保存对应频道或执行“保存并应用”时迁移为 `open`，页面刷新不会静默改动配置。
- 频道凭据按镜像适配器约定使用 Secret 字段；旧值只显示掩码，输入新值后才提交更新。
- 每张已配置频道卡片可单独保存该频道（不重载 Gateway）；页面右上角只保留刷新与“保存并应用”，后者会保存当前所有未保存草稿并统一重载 Gateway。其他角色只读。

237 的核验确认了当前飞书、钉钉和企业微信适配器的包标识、版本和上述配置路径；BFF 仅把插件标识与启用状态回传页面，插件配置内容不回传。2026-07-20 完成依赖修复和飞书升级后，用户确认三频道真实消息均可正常回复；这证明当前正向收发可用，但仍不替代私聊/群聊覆盖、断网重连、冷启动恢复、失败状态和会话隔离的完整交付验收。

## 3. 配置和凭据边界

```text
浏览器频道管理页
→ Admin BFF 认证、权限、审计和配置脱敏
→ GAIOP Gateway config.patch/config.apply
→ ISO 预装频道组件读取配置并建立连接
```

- 频道运行配置的权威存储仍是 Gateway 配置，不重复保存到 Admin SQLite。
- 浏览器只调用频道专用 `GET /api/channels/config`；BFF 在内部读取 Gateway 配置后，无论浏览器角色是否为管理员，Token、Secret、密码、密钥等旧值均替换为掩码。页面只获得安全的插件清单（标识与启用状态），不获得插件配置内容。
- 掩码值不得作为更新内容写回；管理员只有输入新值时才产生 Secret patch。
- 页面、响应、日志、审计和 Git 中不得出现真实频道凭据、Webhook、私钥或安装命令。
- Admin 只记录“谁修改了哪个频道、保存/应用是否成功”，不记录配置值。
- 飞书扫码二维码及其一次性授权链接只返回发起该会话的管理员；它们属于短时敏感授权材料，不写入 SQLite、审计或服务日志。扫码成功后的 `appSecret` 不经过页面，也不会由 API 回显。

## 4. 权限

| 操作 | basic | auditor | standard | admin |
|---|---:|---:|---:|---:|
| 查看频道安全运行状态 | 否 | 是 | 是 | 是 |
| 创建配置草稿 | 否 | 否 | 否 | 是 |
| 修改启停、身份字段和凭据 | 否 | 否 | 否 | 是 |
| 保存/应用 Gateway 配置 | 否 | 否 | 否 | 是 |
| 发起/查看/取消本人飞书扫码会话 | 否 | 否 | 否 | 是 |
| 下载或安装频道组件 | 不提供 | 不提供 | 不提供 | 不提供 |

前端禁用按钮只是交互提示，BFF 对 `config.patch/config.apply` 的服务端管理员权限仍是最终边界。

标准和审计用户页面使用“安全运行状态”标题，下面只保留组件安装/可用状态和是否已配置等状态标签，不显示“仅展示组件、配置和运行可用状态……”说明，也不返回频道配置内容。基础用户进入频道管理统一显示“无访问权限”。

## 5. 会话关系

企业微信等外部频道使用系统设置中的智能体上下文空闲时间。超过设定时间无用户消息后，下一条消息建立新上下文。频道会话必须按频道、账号和对端隔离，不能共享其他用户上下文。

该归属与空闲策略尚未完成三频道真实联调，当前频道配置页面不得把“配置已保存”解释为“外部会话归属已完成”。

## 6. 异常与验收

- 组件缺失、组件状态未知、未配置、配置停用、认证失败和运行时断开必须区分。
- 保存配置与应用配置分别反馈；Gateway 重连超时不能显示成功。
- 新草稿默认停用；实际启用前必须补齐镜像适配器要求的必填字段。
- “需配对批准”是外部私聊的正常安全状态，不应误报为凭据或连接失败；批准配对属于受控的服务器运行时操作，必须另行授权并留审计。
- 飞书“扫码开通”只负责创建或取得飞书应用凭据，私聊准入固定跟随飞书应用可见范围；它不查询员工目录，也不管理外部用户配对。
- 非管理员直接调用配置写 RPC 必须被 BFF 拒绝。
- 页面、浏览器网络响应和日志中不得出现旧凭据明文。
- 页面不得出现底层框架品牌、外部安装链接、包安装命令或服务器路径。
