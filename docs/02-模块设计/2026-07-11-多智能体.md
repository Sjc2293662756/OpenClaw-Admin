## 1. 目标

管理查询、分析、诊断和报告等不同职责的智能体资源，并为复杂运维任务提供协作基础。

## 2. 当前功能

- 智能体数量、关联会话、Token 和模型统计。
- 列表、刷新、创建、详情和删除。
- ID、名称、工作目录、身份、主题、表情、头像。
- 模型选择、工具允许/拒绝策略和相关参数。

## 3. 权限与安全

基础/审计只读；标准用户当前不应创建、删除或改变智能体结构；管理员执行资源管理。工作目录和工具策略属于高风险配置，服务端必须拒绝标准用户相关 RPC。智能体不能绕过当前用户、Skill 和数据源权限。

## 4. 异常与验收

- ID 重复、工作目录越界、模型不存在、工具策略无效应拒绝。
- 删除已有关联会话/任务的智能体前需提示影响并按 Gateway 能力处理。
- 非管理员直接调用智能体修改 RPC 返回权限错误。

## 5. 与智能体工坊的分工建议

本模块应定位为“智能体资源管理”：创建、模型、工具、身份和状态。智能体工坊定位为“场景编排与协作视图”，不重复提供完整资源 CRUD。该建议尚需产品确认后实施。
