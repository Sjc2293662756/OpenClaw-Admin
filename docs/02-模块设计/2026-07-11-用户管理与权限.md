## 1. 功能

- 用户列表：更新时间、用户名、角色、描述和状态，支持用户名/描述搜索、角色/状态筛选、前端分页和刷新；审计用户只读查看安全账户信息，管理员额外获得操作列和管理入口。
- 新增：用户名、可选描述、四类角色、密码/确认、激活状态；普通管理员不能选择管理员角色。
- 编辑：管理员可修改用户描述、角色和激活状态；用户名当前不可修改。
- 修改密码：用户校验当前密码后修改本人密码；管理员管理他人密码必须使用重置流程。
- 重置：管理员输入并确认符合规则的临时密码，注销目标用户已有会话，并要求目标用户首次登录修改密码。
- 删除：管理员删除用户；禁止删除自己和最后一个激活管理员。

## 2. 角色权限

下表以当前正式角色矩阵为准。“查看”表示可进入且为只读；“操作”表示可在其数据范围内执行页面已提供的业务动作；“管理”表示可配置、创建、修改或删除。“无”表示既不提供可用页面入口，也不能通过 REST/RPC 直接绕过。

| 模块 | 基础用户 | 审计用户 | 标准用户 | 管理员 |
|---|---:|---:|---:|---:|
| 仪表盘 | 无 | 查看 | 查看 | 查看 |
| 告警中心 | 无 | 查看 | 查看 | 查看及管理员配置 |
| 对话工作台 | 查看、发起本人对话；左侧仅显示本人历史；可删除本人会话；左下角可修改本人密码 | 查看工作台及历史，只读 | 查看、发起本人对话；左侧仅显示本人历史；可删除本人会话；左下角可修改本人密码 | 查看、操作全部已授权会话；左下角可修改本人密码 |
| 会话管理 | 无；本人历史仅在对话工作台左侧提供 | 查看全部会话，只读 | 查看、续聊、删除本人会话 | 查看、操作全部已授权会话 |
| 报告与文件 | 无 | 查看全部列表、预览和下载，只读 | 查看、预览和下载本人数据 | 管理全部已授权数据，可删除 |
| 任务计划 | 无 | 查看全部任务，只读 | 无 | 创建、修改、启停和删除 |
| 频道管理 | 无 | 查看脱敏后的安全运行状态，只读 | 查看脱敏后的安全运行状态，只读 | 管理频道配置；敏感字段始终不在页面或普通响应中明文展示 |
| Skills | 无 | 查看安全运行状态，只读 | 查看安全运行状态，只读 | 管理 |
| 系统监控与运行设置 | 无 | 查看 | 查看 | 查看及管理允许的运行设置 |
| 审计日志 | 无 | 查看、筛选和导出 | 无 | 查看、筛选和导出 |
| 账户管理 | 无；仅可在对话工作台修改自己的密码 | 查看账户安全投影，只读；可在用户管理中修改自己的密码 | 无；仅可在对话工作台修改自己的密码 | 管理账户；也可在用户管理中修改自己的密码 |
| 记忆、模型、智能体、工坊、系统配置、数据源与系统升级 | 无 | 无 | 无 | 管理 |

### 2.1 修改密码的返回规则

修改密码按**打开页面的来源**返回，而不是按角色统一跳转：

- 任一角色从对话工作台左下角头像打开“修改密码”，完成或取消后均返回原对话工作台及原查询参数（例如当前会话）。
- 只有审计用户和管理员能进入“账户管理”。审计用户仅可查看账户；两者从该页面打开自己的“修改密码”，完成或取消后返回账户管理。
- 基础用户和标准用户没有账户管理页面，因此两者的本人改密入口均仅在对话工作台；这不改变标准用户原有的仪表盘、告警、会话、报告和安全状态查看权限。

### 2.2 初始管理员与新建管理员

初始管理员与新建管理员同属“管理员”角色，拥有相同的业务模块管理能力；区别仅限于管理员账户的创建和相互管理边界，初始管理员不是第五种业务角色。

| 账户管理事项 | 初始管理员 | 新建管理员 |
|---|---|---|
| 创建基础、审计、标准用户 | 可以 | 可以 |
| 创建管理员 | 可以 | 不可以 |
| 管理基础、审计、标准用户 | 可以 | 可以 |
| 管理其他新建管理员（编辑、停用、降级、重置、删除） | 可以 | 不可以 |
| 管理初始管理员 | 不可以；初始管理员受保护 | 不可以 |
| 修改自己的密码 | 可以 | 可以 |
| 修改自己的角色、状态或删除自己 | 不可以 | 不可以 |

系统只允许一个 `is_initial_admin=1`。该标记不能从页面或普通接口转移；初始管理员不能被删除、停用、降级或由他人重置密码。任何管理员均不能删除最后一个激活管理员。

## 3. 数据与安全

用户存于 SQLite `users` 表；密码使用随机盐与 scrypt 哈希，接口不返回哈希。用户名忽略大小写唯一，最长64；密码至少8位且同时包含英文字母和数字，允许中文、空格和特殊符号；描述最长500；状态为 `active/inactive`。

`users` 表新增：

- `is_initial_admin`：唯一初始管理员保护标记，现有库幂等迁移时选择最早创建且仍激活的管理员；新安装首个管理员自动标记。
- `must_change_password`：管理员重置后置为1；现有用户迁移默认0；本人改密成功后清零。

迁移不修改既有密码哈希、角色和状态。`idx_users_single_initial_admin` 部分唯一索引保证最多一个初始管理员。

前端权限只用于体验，REST 中间件和 `/api/rpc` 决策是最终边界。非管理员读取 Gateway 配置时，密码、Token、API Key、Secret、Credential 等字段被掩码。

`GET /api/users` 只允许审计和管理员访问。审计响应仅包含账户标识、用户名、角色、描述、状态、初始管理员标记和创建/更新时间，不返回密码哈希或 `must_change_password` 等账号安全内部状态；新增、编辑、重置密码、启停和删除接口仍只允许管理员访问。

## 4. 异常

- 非法输入、用户名重复、用户不存在、密码过短、当前密码错误。
- 同一用户名连续失败5次后锁定5分钟；用户名大小写不敏感，成功登录清空计数，服务重启后计数清空。
- 不存在用户、停用用户和密码错误对外统一返回“用户名或密码错误”。
- 禁止删除当前用户、禁止删除最后一个激活管理员。
- 管理员不能通过用户编辑接口修改自身账户，只能正常修改自己的密码；禁止通过编辑移除最后一个激活管理员。
- 普通管理员不能创建、提升或管理管理员；初始管理员可管理其他管理员。
- 初始管理员不能删除、停用、降级或被他人重置；标记不能通过页面或普通接口转移。
- 修改/重置密码后撤销其他活动 Token，避免旧会话继续使用。
- 角色或状态变化后撤销目标用户已有 Token，使新权限在重新登录后生效。
- 被重置用户登录后只能进入“修改我的密码”；统一认证中间件拒绝其他REST、工作台和Gateway RPC。改密成功后撤销原Token并要求重新登录。

## 5. 验收标准

- 四类角色分别验证查看、对话、任务、频道、Skills、账户和安全配置；审计用户可读取账户安全投影，但所有账户管理写接口均返回403。
- 直接调用接口或 RPC 不能绕过前端禁用。
- 密码不在列表、审计、日志和响应中出现。
- 初始管理员、最后管理员、普通管理员管理范围和会话失效机制有效。
- 直接调用REST或RPC不能绕过首次改密和管理员层级限制。

## 6. 已知限制

尚无用户名修改、服务端分页搜索、组织/租户和持久化登录锁定。会话和报告已按登录用户稳定 ID 实施归属过滤；外部频道身份不映射为 GAIOP 登录用户，仅审计和管理员可按各自权限查看。初始管理员遗忘密码留给部署侧受控恢复，不设置固定后门。
