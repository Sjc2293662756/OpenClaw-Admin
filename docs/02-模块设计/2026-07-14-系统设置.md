## 1. 定位

系统设置管理日常使用策略，不保存部署地址、NAPM 密码、Gateway Token、证书私钥或任意环境变量。

## 2. 分区

| 分区 | 状态 | 内容 |
|---|---|---|
| 基本设置 | 已实现 | 只读品牌“观枢 GAIOP”与产品版本 `v1` |
| 会话设置 | 已实现（Gateway 实机联调待验） | 登录会话、管理端空闲、外部渠道上下文、历史保留 |
| 报告存储目录 | 已实现只读回显；目录分层待双端适配 | 管理员通过 Admin BFF 只读查看部署配置的报告根目录；AI 报告按用户与报告类型分层落盘待后续实现 |
| 界面偏好 | 已实现 | 界面语言（中文/English）与明暗主题；均只保存在当前浏览器本地，不写入 Admin BFF 或 GAIOP 运行时 |

四个分区统一在 `/settings` 页面纵向展示，不再通过独立的基本设置或报告存储占位页跳转。会话设置仍使用独立 BFF 接口和独立保存动作，避免 Gateway 同步失败影响其它区块。

## 3. 会话设置

| 设置 | 范围 | 默认 | 生效方式 |
|---|---:|---:|---|
| 登录会话时长 | 1–168 小时 | 24 | 影响新登录 Token 的最大有效期 |
| 管理端空闲超时 | 0–1440 分钟 | 0 | 大于 0 时受认证请求刷新活动时间 |
| 智能体上下文空闲时间 | 1–1440 分钟 | 30 | 保存到 Gateway `session.reset`，外部渠道下一条消息新上下文 |
| 历史会话保留 | 0–3650 天 | 180 | 当前只保存策略，不执行删除；0 为长期保留 |

Web 对话工作台保留用户主动打开历史继续分析的能力，不强制弹窗、跳转或自动新建页面会话。渠道覆盖使用 10 年空闲窗口目前仅为待验证的管理策略；浏览器不标注来源路由字段。

### 2026-07-15 兼容性状态修正

该渠道覆盖仍可作为管理员设置的目标策略显示，但当前版本不再把 `webchat` 来源字段从浏览器传给 Gateway。现有 Gateway 要求来源路由字段必须成对且版本兼容，单独字段会阻断对话发送。故页面不得显示或暗示“10 年窗口已在当前工作台运行生效”；真实生效状态为“Gateway 联调待验证”。后续只允许由 Admin BFF 适配完整路由参数并完成验证后再恢复该状态。

## 4. 权限与事务边界

所有登录用户可读取会话策略，仅管理员保存。浏览器只调用 Admin BFF；BFF 负责把稳定的管理字段转换成 Gateway `config.patch` 参数、处理 raw/legacy 参数版本兼容、读取不含敏感字段的运行时回显并写入审计。BFF 会先同步 Gateway，成功后再写 SQLite；Gateway 失败时不会保存管理策略。

Gateway 成功而 SQLite 失败仍不是原子事务，BFF 返回明确错误，管理员可重试以恢复一致状态。当前本地已完成适配层和模拟测试，真实 Gateway 写入联调留待统一部署阶段。

## 5. 验收标准

- 范围外输入被拒绝；非管理员 PUT 返回 403。
- 外部渠道使用配置的空闲时间；Web 工作台不被该时间强制切换。
- 历史保留设置不会立即删除任何会话。
- 保存操作写审计且不记录敏感信息；运行时回显不得返回 Gateway 完整配置、Token 或密码。

## 6. 后续

管理员只读接口为 `GET /api/system-settings/report-storage`，返回 `reportStorageRoot`；仅管理员可访问，且每次成功读取均写入审计。该接口不接受路径参数、没有写入方法，也不返回任何凭据。报告根目录、用户目录和报告类型目录的后续双端契约见《报告目录分层与双端适配规划》。在 GAIOP 与 Admin 联调前，页面不得宣称已按该结构落盘。Gateway 写入的真实版本兼容性在统一部署联调阶段验收。
