正式 GAIOP 告警接收、持久化和 Admin 适配以《`docs/04-公共设计/2026-07-16-GAIOP-Admin与GAIOP双端契约v0.1.md`》为实现基线；本模块当前只读 SSH 数据源仍是过渡方案。

## 1. 范围

告警通知页面只展示 NAPM 经 Syslog 写入 Ubuntu OpenClaw 服务器的告警记录，支持严重级别、类别、关键字筛选与详情查看。

不提供告警规则编辑、NAPM 写入、Syslog 配置、OpenClaw 配置、服务启停或任意远程命令执行。

## 2. 数据链路

```text
NAPM → Syslog → Ubuntu 日志文件
     → GAIOP-Admin BFF（受限只读 SSH）
     → 结构化告警接口 → 管理页面
```

BFF 固定执行受控的 `tail` 读取，浏览器不能传入远程命令、服务器地址或日志路径。原始日志仅在 BFF 内存中解析，接口不返回原始行、SSH 地址、日志路径、账号、密码或私钥。

## 3. 解析契约

复用 GAIOP `openclaw-napm-syslog-watcher` 已验证的 Syslog 格式：时间、来源、类别、严重级别、告警名称、规则 ID、事件 ID、告警描述、分组、开始/结束时间和指标列表。告警类型权威映射来自 GAIOP `openclaw-napm-alert-query/services/AlertConstants.js`：网络性能、网络异常、应用性能、业务故障、用户体验、安全事件、智能分析。页面筛选固定展示全部七类，即使当前日志中没有对应类型。GAIOP 本次未修改；若其 Syslog 解析契约或分类常量变化，需同步更新 Admin 的解析器与测试。

## 4. 权限与审计

- 所有登录用户可只读查看告警。
- 每次成功列表读取写入 Admin 审计，记录返回数量，不记录原始内容或 SSH 配置。
- 页面无写操作，因此没有远端变更权限。

## 5. 运行时配置

部署环境通过以下变量配置只读 SSH 数据源：`GAIOP_ALERT_SSH_HOST`、`GAIOP_ALERT_SSH_PORT`、`GAIOP_ALERT_SSH_USERNAME`、`GAIOP_ALERT_SSH_PASSWORD` 或 `GAIOP_ALERT_SSH_PRIVATE_KEY_PATH`、`GAIOP_ALERT_SYSLOG_PATH`。

真实密码和私钥不得写入代码、Git、文档、接口响应或审计日志。生产应优先使用仅有日志读取权限的 SSH 私钥。

## 6. 接口

`GET /api/alerts` 需要登录认证，支持 `severity`、`category`、`keyword`、`startAt`、`endAt`、`page`、`pageSize` 与 `maxResults`。`GET /api/alerts/time` 返回 BFF 当前时间，供页面生成和展示筛选区间，避免依赖浏览器电脑时钟。默认范围为最近 1 小时；快捷范围包括今日、昨日、最近 7 日、最近 30 日和本月，点击后立即查询；自定义范围需要在日历面板中确认或取消。BFF 只返回当前页，默认每页 10 条；页面可选择 10/20/50/100 条每页，并可设置 `TOP 50/100/200/500/1000` 或自定义上限（最大 3000）。关键字只检索告警名称、来源 IP 与事件 ID，不检索告警描述。`POST /api/alerts/export` 仅接收当前页六个展示字段，生成带冻结表头和筛选器的 `.xlsx` 文件；复制和导出均不额外读取 Syslog。BFF 按读取上限读取最近日志，并在进程内复用 60 秒只读缓存；因此翻页、时间或普通筛选不会在缓存有效期内重复建立 SSH 连接。成功响应返回脱敏后的 `alerts[]`、分页状态和解析统计；数据源未配置、SSH 不可用或日志不可读时返回 `503 ALERT_SOURCE_UNAVAILABLE`。

## 7. 告警详情分析交接

Syslog 详情保留 `condition`、`elogid`、`starttime`、`endtime` 和触发指标。页面在指标下方回显触发条件；依据与 GAIOP `openclaw-napm-syslog-watcher` 一致的分钟对齐窗口生成“分析告警数据包”指令。用户点击详情卡片中的“告警数据包详细分析”后，指令通过一次性路由交接值移交到 GAIOP-Admin 新对话输入框，工作台读取后立即清除该值；会话存储仅作兼容回退，不写入审计明细或远端日志。缺少 Event ID 或开始时间时明确标记为未记录并禁用按钮。本次没有修改 GAIOP。

## 8. 2026-07-15 实现补充与当前边界

### 8.1 页面与查询体验

- 默认按 BFF 当前时间查询最近 1 小时，避免浏览器本机时间不准导致查询窗口偏移；筛选器上方始终展示已生效的起止时间。
- 快捷范围包括最近 1 小时、今日、昨日、最近 7 日、最近 30 日和本月；点击非“自定义”范围后立即查询。自定义范围展开双日历与时间输入，必须点击确认才生效，取消则保留原范围。
- 列表是服务端分页而不是一次性加载全部记录：默认每页 10 条，可选 10/20/50/100 条；读取上限为 `TOP 50/100/200/500/1000` 或自定义值，后者最大 3000。搜索范围为告警名称、来源 IP、事件 ID，不检索告警描述。
- 级别、类型筛选始终含有明确的“全部”选项，避免空白选择框。页面提供复制当前页内容和导出当前页 Excel；导出由 BFF 根据当前已展示的脱敏字段生成，不再次读取 Syslog。

### 8.2 只读数据源性能与降级

- BFF 每次远端读取的行数与 `TOP` 上限一致；默认 `TOP 200` 只读取最近 200 行，不会无条件读取全部日志。
- 成功读取结果在进程内缓存 60 秒，翻页和普通筛选在缓存有效期内不会重复建立 SSH 连接；远端读取的超时为 45 秒，以容纳较慢的日志读取。
- 缓存存在时若新的远端读取失败，接口返回上一次成功的只读快照并标记为过期，页面明确提示数据并非最新；从未读取成功时仍返回 `503 ALERT_SOURCE_UNAVAILABLE`。
- 已在本地 BFF 对受控 Syslog 读取完成真实冒烟：默认读取、解析、分页和缓存命中均正常。该验证不改变 Ubuntu/OpenClaw、NAPM 或 GAIOP 服务器上的任何配置。

### 8.3 详情与对话交接

- 详情展示原始触发条件和触发指标；缺失字段显示“未记录”，不根据级别反向伪造条件。
- 对每条具备事件与时间窗口的告警，页面生成 `分析告警数据包 eventId=<id> start=<epoch> end=<epoch> <指标>` 指令；时间窗口遵循现有 GAIOP watcher 的分钟对齐逻辑。
- 操作名称为“告警数据包详细分析”。点击后先进入新的工作台欢迎态，再将指令移交给输入框；不写入 URL、审计详情或远端日志。父级工作台读取一次路由交接值后立即移除查询参数，再通过页面属性传给输入区；会话存储仅作兼容回退。
- 创建新会话时会先清空前一个会话的本地消息预览，避免先显示旧会话、数秒后才切换为新会话的割裂体验。
- 从告警详情进入的工作台会话在页头显示单向“返回告警通知”。返回时恢复本次进入前的时间范围、级别、类型、来源关键字、分页、每页条数与 TOP 上限；返回后立即清除这份浏览器会话状态，普通工作台和普通告警页面不会显示该按钮或误用旧筛选。
