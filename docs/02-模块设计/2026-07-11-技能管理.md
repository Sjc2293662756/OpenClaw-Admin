## 1. 目标

管理 GAIOP 智能体可调用的 Skills。NAPM 查询、告警、巡检、数据包、诊断和报告能力以 Skill 形式被对话或任务调用，Skill 不是独立的前台业务菜单。

## 2. 当前功能

- 按用户、工作区、托管、额外和内置来源分组。
- 名称、描述、来源、版本、可用性和受限状态。
- 搜索、是否显示内置技能、单技能对话可见性。
- 标准用户/管理员可按服务端 RPC 策略执行 Skills 安装和更新。

## 3. 数据源关系

主要 NAPM Skills 共用权威运行数据源配置。管理员在数据源管理中切换运行数据源后，常规查询、告警查询、巡检、汇总、数据包和报告相关调用应统一读取运行时桥接；不是每个 Skill 独立维护 NAPM IP。

## 4. 权限与安全

- 基础/审计：只读。
- 标准：可使用、安装/更新被允许的普通 Skill，不可修改底层凭据和全局安全配置。
- 管理员：安装、更新、启停和管理全部配置。
- Skill 结果必须绑定请求会话，禁止把上一次用户结果复用给另一用户。

## 5. 异常与验收

- 缺依赖、版本不兼容、数据源不可用、权限不足应分别提示。
- 切换运行数据源后，受支持的 NAPM Skills 使用同一目标，不接受请求参数绕过权威目标。
- 安装/更新失败不破坏当前可用版本；敏感环境值不在日志或页面回显。

## 6. 后续

建立 GAIOP 业务能力与 Skills 的正式映射、版本兼容矩阵、回滚、发布审核和完整审计。
