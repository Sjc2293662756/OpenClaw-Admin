## 1. 目标与边界

管理 GAIOP 智能体使用的模型供应商、模型列表、主模型和参数。模型供应商凭据与 NAPM 数据源凭据是不同安全域。

## 2. 当前功能

- 供应商/模型总览、当前主模型和刷新。
- 常用供应商快速配置、自定义供应商、创建、编辑和删除。
- 配置供应商 ID、API 协议、基础地址和 API Key。
- 模型增删、能力选择、设为主模型、配置差异和 JSON 预览。

## 3. 权限与安全

基础/审计只读；标准用户仅调整允许的普通模型选择；供应商、基础地址、API Key 和全局主模型应由管理员管理。非管理员不得读取完整密钥，审计不得记录密钥值。

## 4. 异常与验收

- 供应商 ID、URL、模型 ID、协议和重复模型必须校验。
- 保存失败时保留草稿并显示 Gateway 原因；不能展示“成功”后静默失败。
- 删除当前使用供应商前必须阻止或要求先切换。
- 管理员保存后刷新能看到一致配置；非管理员配置响应中的敏感字段被掩码。

## 5. 后续

落实字段级权限、凭证统一存储/轮换、模型连通性测试、变更审计和影响提示。
