## 1. 目标与边界

管理智能体长期记忆、规则和业务资料，用于对象别名、业务说明、用户偏好和分析规则。它不是全局文件浏览器，也不是任意服务器文件编辑器。

## 2. 当前功能

- 选择智能体并加载记忆文件。
- 按系统、用户、工作区等来源分组。
- 识别 AGENTS、SOUL、IDENTITY、USER、TOOLS、HEARTBEAT、BOOTSTRAP、MEMORY 等内部文件。
- Markdown 查看、编辑、保存、取消和恢复。
- 插入事实、原则、人格、启动、偏好、心跳和项目约定模板。

## 3. 权限与安全

基础/审计用户只读；标准用户只允许修改授权记忆；管理员可管理全局规则。后端必须限制智能体和文件范围，防止通过文件名访问其他目录。敏感凭据不得写入记忆。

## 4. 异常与验收

- 文件不存在、智能体不可用、保存冲突或 Gateway 断开应保留用户编辑内容。
- 无权限用户不能进入可编辑状态，直接 RPC 也应被拒绝。
- 保存成功后重新读取内容一致，取消不产生远端修改。

## 5. 后续

明确记忆所有者、发布范围、审核、版本与回滚；完成智能体级数据隔离后再开放标准用户编辑。
