# 配置生效与运行时边界

| 属性 | 内容 |
|---|---|
| 创建日期 | 2026-07-15 |
| 状态 | 当前实现基线 |

## 1. 为什么区分“保存”和“生效”

GAIOP 同时存在管理数据库、管理服务 `.env`、Gateway 配置、运行时桥接和操作系统配置。页面保存成功只代表对应存储写入成功，不能统一解释为所有服务即时生效。

## 2. 配置类型

| 配置 | 存储 | 当前生效方式 |
|---|---|---|
| 用户/权限 | SQLite | 管理接口即时读取；已有 Token 带登录时角色，角色编辑目前未实现 |
| 登录/空闲策略 | SQLite | 新登录或后续请求检查 |
| 外部渠道上下文 | Gateway config | `config.patch` 后由 Gateway 使用 |
| Web 工作台渠道覆盖 | Gateway config + `originatingChannel` | 发送时匹配 webchat |
| 主机网络 | SQLite | 仅保存，不修改 OS |
| 数据源列表/测试 | SQLite + 服务端请求 | 保存/测试即时 |
| 运行数据源 | SQLite + `GAIOP_ACTIVE_DATA_SOURCE_FILE` | Admin 写入，GAIOP Skills 在调用前读取 |
| 环境敏感配置 | SQLite | 当前不自动消费、不写 `.env` |
| 报告目录 | 进程环境变量 | 服务启动时确定，两个服务需一致 |
| Gateway 地址/Token | 管理服务 `.env` | 服务启动加载；内部仍使用兼容变量名 |

## 3. 权威数据源优先级

NAPM Skills 的目标优先使用运行时桥接；没有桥接时回退已有 `NETINSIDE_*` 环境变量。用户对话参数不得任意覆盖管理员启用的权威数据源。切换数据源是显式管理员动作，不根据连接失败自动切换。

## 4. 配置项未来标准

每个可管理配置都应声明：键、类型、默认值、是否敏感、消费者、校验、权限、生效方式（即时/重连/重启/仅部署）、失败恢复和审计摘要。未登记白名单的键不得由 Web 页面创建后直接注入进程环境。

## 5. 跨存储一致性

会话设置目前跨 Gateway 与 SQLite，不是原子操作，但由 Admin BFF 统一编排为先 Gateway、后 SQLite：Gateway 不可用或同步失败时不保存 SQLite；SQLite 失败时明确提示重试。报告删除跨文件系统与 SQLite；数据源启用跨 SQLite 与桥接文件，但在数据库事务回调中写文件，失败会回滚数据库。文档和页面应针对每类操作提供真实的成功语义和恢复方式。
