# GAIOP 公司与产品名称统一及平台品牌配置

## 1. 目的与状态

- 实施日期：2026-08-07
- 代码仓库：`GAIOP-Admin/dev-yangshuo`
- 页面路由：`/platform-branding`（隐藏路由，不加入前端菜单）
- 本文定义对外展示名称的唯一默认基线，以及初始管理员可修改的受控机制。

技术兼容标识（例如 API 字段、存储键、插件标识和内部 OpenClaw 名称）不属于本机制的替换范围；仅处理用户可见的公司与产品文案。

## 2. 八项默认名称

| 字段 | 默认值 |
| --- | --- |
| 公司简称 | 北京网深科技 |
| 公司法定全称 | 北京网深科技有限公司 |
| 公司英文名 | Beijing Wangshen Technology Co., Ltd. |
| 公司品牌（英文简称） | NetInside |
| 产品代号 | GAIOP |
| 产品中文简称 | 观枢 GAIOP |
| 产品中文全称 | 观枢 GAIOP 智能运维分析平台 |
| 产品英文全称 | Guanshu AI-driven Operations Platform |

默认值的唯一代码来源为 `server/platform-branding.json`。前端 `src/branding/platform.ts` 和服务端品牌设置模块均从该文件取得初始值，避免页面、翻译资源和服务端各自维护一套名称。

## 3. 管理与权限边界

- 仅初始管理员可访问 `/platform-branding`、读取后修改八项名称或恢复默认值。
- 前端路由守卫、页面权限判断和服务端 `GET`/`PUT`/`POST reset` 接口均实施初始管理员限制，不能通过直接调用写接口绕过页面隐藏。
- 当前值保存于 Admin SQLite 的 `branding_settings`；发布迁移只新增该设置表，不替换用户、会话、审计或其它运行数据。
- “一键恢复默认名称”会恢复本表所列八项值，确认提示为“确认恢复默认的八项名称？”。

## 4. 视觉规则

- 入口欢迎页、登录页和对话工作台均使用当前公司品牌字段。
- 当全部八项当前值与本文件第 2 节的默认值完全一致时，`NetInside` 按既有品牌字标显示：`Net` 为绿色 `#50ae65`，`Inside` 使用页面原有深色文字色。
- 初始管理员保存任意自定义名称后，品牌字段按完整纯黑文本显示，不为任意自定义内容拆分或着色。
- 执行恢复默认后，双色 `NetInside` 自动恢复。路由、内部协议和技术标识不改变。

## 5. 验收范围

- 初始管理员可通过隐藏地址查看八个独立输入项、保存并恢复默认值。
- 普通管理员和其它角色访问该路由或直接调用写接口均被拒绝。
- 默认与自定义两种状态下，欢迎页、登录页、对话工作台的品牌文本和字标样式符合第 4 节。
- 发布与 237 验证结果记录在 `05-部署运维/2026-08-07-237本地品牌预览与平台品牌发布记录.md`。
